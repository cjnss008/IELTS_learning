# IELTS Learning · 雅思 52 篇学习包

当前版本：**0.0.0**（见 [VERSION](VERSION)）。这是现有学习包纳入版本管理的初始基线。

项目围绕 52 篇英语文章提供离线阅读、英式音频跟读、词汇练习和自测。前 40 篇来自原学习材料，第 41—52 篇为新编补充；学习记录保存在当前浏览器本机。

## 开始学习

1. 保持整个文件夹结构完整，用浏览器打开 **[开始学习.html](开始学习.html)**。
2. 在左侧选择课文，按需使用正常语速、慢速段落跟读、中英对照、单词释义和默写练习。
3. 定期使用页面的“导出学习记录”功能备份进度；换浏览器、换设备或清理浏览器数据后，记录不会自动同步。

网页和音频可离线使用，无需安装应用、构建项目或启动后端服务。页面中的外部词典等链接需要联网。详细操作见 [使用说明.md](使用说明.md)。

### 在其他位置获取完整副本

先安装 Git 和 Git LFS，再运行：

```powershell
git lfs install
git clone https://github.com/cjnss008/IELTS_learning.git
cd IELTS_learning
git lfs pull
```

已有 NAS 工作目录已初始化，无需再次克隆。EPUB 约 160 MiB，超过 GitHub 普通 Git 文件的 100 MiB 上限，因此通过 [Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github) 保存；未使用 Git LFS 的副本可能只拿到指针文件。

## 版本与 GitHub 同步规则

1. 初始版本为 **0.0.0**，首次上传并建立标签 **v0.0.0**。
2. 每完成一次可独立说明的功能修改或修复，将末位版本号加 1：`0.0.1 → 0.0.2 → …`。版本号采用三段数字记录，本阶段不自动在 10 时进位。
3. 每次完成修改，同步更新 `VERSION`、本 README 的当前版本及 [CHANGELOG.md](CHANGELOG.md)，完成必要检查后提交到本地 Git。
4. **每累计 10 个小版本，向 GitHub 推送一次**：下一个同步点为 **0.0.10**，之后为 **0.0.20、0.0.30**，依此类推。推送时包含这批本地提交，并建立对应的 `v0.0.10` 等标签。
5. 未到同步点时保留本地提交；用户明确要求提前上传时，按当次要求执行。大版本调整另行约定。

例如，到达 0.0.10 且验证完成后执行：

```powershell
git tag -a v0.0.10 -m "Release 0.0.10"
git push origin main
git push origin v0.0.10
```
