# IELTS Learning · 52 周 Academic 自学

当前版本：**0.0.27**（见 [VERSION](VERSION)）。

面向成人近零基础学习者的本机自学软件。课程覆盖 **52 周、364 个学习日**，以听说读写各 7.0 为内部训练目标，为正式考试各 6.5 留出余量。每天 6 小时是总可用预算，材料学会后立即继续；时间、重复题正确率和 AI 估计都不是考试成绩保证。

## 开始使用

1. 安装 Node.js 22 或更新版本，双击 **启动学习.cmd**。启动器检查并复用本项目的本机服务，打开统一首页。
2. 每天从 **[今日学习](今日学习.html)** 继续，按词汇、语法、听力、阅读、口语、写作、错题与复盘的顺序进入具体材料。
3. 在 **AI 设置** 分别配置 DeepSeek 和阿里云专业语音服务。密钥仅驻服务内存，重启后重新填写。学习资料、已有音频和原稿可本地保存；需要真实评阅的项目在服务未就绪时保持待评。
4. 在 **52 周进度** 设置开课日期；在 **备份中心** 定期分别导出文字作品与原始录音。

统一服务地址为 `http://127.0.0.1:8765/`。file://、localhost、127.0.0.1、不同端口和浏览器各自保存数据，迁移前须在原入口导出。

## 六小时怎样使用

常规参考分配为词汇 45、语法 30、听力 75、阅读 60、口语 60、写作 75、复盘 15 分钟。它们是预算建议，**不是每项必须坐满的最低时长**。10 分钟已完成当前材料并取得相应证据，就继续下一份；不会靠等待计时凑完成状态。

系统记录真实活动时间，排除暂停和后台停留。新课程按真实交付、评阅和错题复盘判断完成，手填数量不能代替作品。旧日程继续保留原单位和原自报规则，旧打卡不会变成已验证掌握。

当天有剩余预算时，追加队列优先核对未完成或待验证的内容，再依据真实表现提供当前程度的常规材料。学得快不直接升级；已经开始的材料保留，关卡与末期保留卷不拿来提前加量。每日 AI 复盘给出的重点和练法会作用于后续尚未开始的常规学习日，保留调整来源与历史。

## 词汇、说写与错题

**词汇学习**先显示绑定必学词的词义、音标、例句与读音。每词完成三遍正确英文输入，再做三次独立、非静音的真实跟读录音。只点麦克风、播放示范、静音或重复使用同一段原音不计跟读。低分的真实跟读保留次数和原音，其问题进入统一错题本。

随后完成 **补全 → 中文写英文 → 听写** 三轮测试。听写需有成功听完的播放记录；拼写按标准英文核对。旧版草稿保留原顺序与原成绩，不能凭旧版通过标记取得新版“三写三读”掌握状态。

**听读与语法**提交原始答案，实际错误自动入本；即使总正确率达到阶段线，仍不会漏掉其中的错题。选项题保留大小写等题意差异，多选须全部且仅选对，填空遵守词数限制。

**写作与口语**先保存原稿，再进行真实反馈。未评、服务失败和旧自评属于待评队列，不自动编造成错误或判为正确。明确的负面评阅、带原稿依据的错误和真实低分才进入错题本。原稿、录音引用、评阅与订正来源保留。

**每日错题复盘**先一次展示当天全部待解决题，填写后整页提交。下一轮只剩仍错或待评的题，已通过项不重复累计；服务暂不可用的题保留输入以便重试。看答案不会删去原错，也不能跳过未通过项完成复盘。当天核心材料完整提交、说写取得真实反馈且错题全部通过后，AI 根据当天材料、首次表现和实际订正进行复盘；新增错误或表现更新会使旧完成状态失效。仅完成部分补充练习不能提前标记全日完成或调整后续日。

英文阅读支持按词悬停查看词义、音标和读音；选中词句后右键打开更详细的语法解释。独立测评禁用帮助，使用过提示的练习保留辅助标记。

## AI 与语音的边界

| 任务 | 使用的证据与通过方式 |
| --- | --- |
| 单词跟读 | 原音和完整阿里云专业结果；保留独立 work/evidence ID 与非静音校验 |
| 例文跟读 | 分段保存原音，自动专业评测，再给中文练法；原音、参考原文和结果可回看 |
| 基础写作 | 两轮对同一原稿的适级目标核对，需有可核对引文；不强行给 A0 短句出 Band |
| 基础口语 | 当前新原稿与新原音的阿里云范围证据，加两轮带原稿依据的阶段反馈；不冒充完整自由口语评分 |
| 高级／完整口语 | 可选 Qwen Omni 对完整原音逐段观察，保留时间点、覆盖和媒体对应，再由文本 AI 双轮复核 |
| 完整 Academic 写口测评 | 各维度真实证据与两轮训练线；缺音频、缺维度或意见分歧时保持待验证／需补强 |

前期专业训练线使用准确度 80、流利度 75、完整度 90；缺少关键维度不算通过。这些 0–100 指标不能换算 IELTS Band。Ali 对给定文本范围的训练诊断与 Omni 的完整自由表达观察有不同用途。

通用 AI 默认 DeepSeek 地址 `https://api.deepseek.com`、偏好模型 `deepseek-flash`，实际模型以连接后返回列表为准。阿里云采用 AppID/AppSecret 动态授权和刷新；Azure、ASR、Omni 是分别配置的可选服务。没有 Omni 时不能补造完整口语四维证据。

费用默认不限额，用量与预算上限为可选功能。录音结束后的自动专业评测及 AI 反馈会发送对应学习内容到所配置服务。密钥和动态 Token 不进入浏览器存储、教材、备份或 Git。

## 课程覆盖与题目质量

`curriculum/coverage.json` 当前为 `complete-material-set`：508 份常规原创源材料，加 8 个听辨专项和 2 个地图专项，组成源材料、派生练习与每日复盘共 1380 项；客观题含语法专项共 6160 题；课程听力音频 210 份。共有 30 套完整题量阅读与 30 套听力，Academic Task 1／Task 2 题目合计 124 题。完整数量见 [覆盖检查](curriculum/coverage.json) 与 [发布验收](curriculum/release-audit.json)。

当前课程编号为 **1–364**。第 4–48 周有 12 组 A/B 关卡；A 卷之后至少间隔 48 小时，再用未曝光 B 卷复测。第 49–52 周另有四套保留末期材料，近期准备度要求三套不同日期的完整证据。基础桥梁、重复题和原 52 篇短文不能替代陌生完整测评。

本次对 **518 个源文件的 5584 道理解题**做规则筛查，Codex 逐题对照了首周 12 份材料的 96 题及全库候选，共 120 道不同题，修改 27 份材料。修正了题干直接给姓名、格式例子恰好给答案、异类干扰项、首周抽象判断和无依据排他推断；听读原文及课程听力音频未改。完整范围、逐项判定和限制见 [题目质量报告](curriculum/question-quality-audit.json)。这不是全题库逐题真人审核，也没有重新进行全库 AI 盲解或真实考生难度标定。

原创场景、合成声音和材料数量不能保证学习效果。先通过 14 天试学检查操作与难度，再观察 4–8 周未见题、延迟保持和辅助依赖；52 周结果需要实际长期表现支持。当前没有独立第 365 天课程调度，未达到目标时应继续补强并另行安排延长周期。

## 备份、资料与离线使用

原始作品、录音及写口归档使用浏览器 IndexedDB；错题复盘、动态计划、曝光和部分旧记录使用档案隔离的浏览器文字存储。文字备份包含原稿、来源、错误尝试、订正轮次与动态计划；音频单独导出，恢复时按原 ID 关联。

错题和个性化计划进入备份白名单，恢复严格校验并合并历史；冲突时停止，保留原记录。切换档案后的旧页面不能误写新档案。`preview=1` 使用独立预览数据，只用于验证。

本地教材为用户授权导入的 41 份不重复 PDF，保留末期卷折叠和曝光记录；目录未提供的配套听力不假装存在。PDF、新课程音频、词音及示范音频按 `.gitattributes` 通过 Git LFS 管理。第三方教材未因随项目保存而获得另行开源授权。
