# IELTS Learning

面向成人自学者的本地英语学习软件，以 Academic IELTS 听、说、读、写各项 7.0 为课程设计目标。每天从“今日学习”进入，按课程、练习、订正和复盘完成学习。

## 每日课程

- 365 天课程框架，整合原 52 篇文章、基础桥梁、分级材料、公开听读资料和本地教材。
- 词汇、语法、听力、阅读、口语、写作与复盘在同一学习流程中衔接。
- 主题关联课程已接入第 2–20 课，每课安排 30 个主题目标词，再配合同主题的听读、语法与说写训练。个人已学词不重复计作首次学习。
- 内置 8000 词参考库；完整全年“每日 30 新词＋跨模块语境”的教学覆盖仍在建设，词库数量不等于已完成教学覆盖。
- 支持入学能力测评与建议课程起点。日常使用固定课表，AI 用于讲解、评阅和复盘。

## 词汇与间隔复习

每词包含中文释义、音标、例句和示范音频。练习依次包括三遍正确输入、三次录音跟读，以及补全、中文写英文、听写测试；测试顺序打乱，错误进入错题本。

间隔复习结合实际学习表现安排认义、拼写、听写和语境表达。全部到期复习纳入队列，不按数量截断；当天未完成的复习与课程保留到后续继续。

## 听说读写训练

| 模块 | 学习内容与反馈 |
| --- | --- |
| 语法 | 中文规则讲解、原文例句、独立练习与订正 |
| 听力 | 分段播放、分角色音色、理解题与听写，区分真人原音和合成示范 |
| 阅读 | 正文与问题分区，阅读时可对照原文作答 |
| 口语 | 录音跟读、阿里云专业评测、错词示范及 AI 反馈；自由口语按所配置语音能力提供相应证据 |
| 写作 | 保存原稿，提交后给出词汇、语法与表达建议，解释修改原因 |
| 复盘 | 集中重做真实错题，保留未通过项，结合当日学习表现生成 AI 复盘 |

学习模块支持悬停查词和划词、划句 AI 讲解。测评中的辅助功能按测评规则限制。服务失败保留原稿与待评状态，不计作答错或通过。

## 学习节奏与学习痕迹

- 每日默认可用时间为六小时，学习与番茄休息共用预算。按剩余时间继续材料，时间不足时保留任务续学。
- 浮动番茄钟支持专注、休息、提前结束今日学习及恢复今日任务。
- 模块显示完成状态和学习次数，已提交内容可回看；“重新学”保留以前的答案与结果。
- 未提交练习可恢复或删除，已输入内容与录音随草稿保留。
- 课程完成、练习次数、AI 评价与实际能力分别记录；考试成绩需要独立测评验证，不能由打卡天数保证。

## 本地使用与数据保护

双击“启动学习.cmd”即可检测运行环境、启动本机服务并打开学习首页。成功后启动窗口自动关闭，出错时保留诊断信息。支持 Windows 与 NAS 共享文件夹使用。

用户配置、进度、原稿、录音和个人资料集中保存在“用户数据”文件夹，也可指定独立存储位置。升级代码保留这些数据；浏览器缓存与文件夹档案核对后继续学习，冲突时保留双方记录。

当天任务完成后自动生成完整备份，保留最近 30 个备份日；备份中心支持手动备份、恢复和清空进度时保留 AI 配置。NAS 内的备份仍依赖 NAS 本身的可靠性。

## AI 与语音服务

通用 AI 和语音评测分别配置。通用 AI 支持填写 API 地址与密钥、获取模型列表并选择模型；阿里云语音服务支持保存项目配置并动态获取和刷新授权令牌。

Windows 按电脑和账户加密保存服务配置，同一电脑与账户重启后恢复。密钥和个人数据不进入 Git；更换电脑或账户时需要首次配置。基础资料和已保存音频可本地使用，AI 讲解与专业语音评测需要网络和有效服务配置。

专业发音指标用于发音诊断，不直接换算 IELTS 分数；AI 评分与学习建议不等同于正式考试成绩。
