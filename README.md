## 开始使用

1. 双击 **启动学习.cmd**。启动器先检测 Node.js；缺少合适版本时自动把随包附带、校验过的运行环境安装到用户文件夹，无需管理员权限或手动设置 PATH。服务就绪后打开统一首页，成功时启动窗口自动关闭；失败时显示错误并保留窗口。
2. 首次可在 **[今日学习](今日学习.html)** 点击 **“开始 AI 能力测评”**，完成听读、写作和原音口语后采用匹配程度的课程起点；也可直接从基础课程开始。之后每天从首页继续，按词汇、语法、听力、阅读、口语、写作、错题与复盘的顺序进入具体材料。
3. 在 **AI 设置** 分别配置 DeepSeek 和阿里云专业语音服务。Windows 默认加密保存到用户文件夹，重启自动恢复；也可关闭持久保存，仅保留本次服务连接。学习资料、已有音频和原稿可本地保存；需要真实评阅的项目在服务未就绪时保持待评。
4. 首次开始学习时自动设置开课日期，也可在 **52 周进度** 调整。**备份中心**显示用户文件夹路径、保存状态、恢复点与个人资料入口。升级时保留整个用户文件夹；仍建议定期额外备份。

统一服务地址为 `http://127.0.0.1:8765/`。请通过启动器使用，直接打开 HTML 文件不能访问用户数据服务。新版在启动课程前先读取文件夹档案；首次升级请从原浏览器、原地址打开一次以迁移旧缓存。多个浏览器有不同修改时停止覆盖并保留冲突候选。

入学测评会逐组显示具体保存状态和剩余步骤。选择题选好后答案已经保存；听力仍需实际完整播放。口语录音保存后，仍需核对实际原话并确认；Windows x64可使用随包本机英文识别，也可使用已配置的云端识别。自动结果可能漏词或改写，须对照原音核对。任意题组都可点击 **“提交四项作答，让 AI 评价”**，缺项时显示清单并定位到对应组；取得完整评价后再点 **“采用此起点，进入今日学习”**。补齐步骤继续使用同一份题目、答案和录音。

如果出现“AI 未连接”，请先在发生问题的那台电脑打开 AI 设置。NAS 共享代码和学习资料，但 Windows 加密配置按电脑与 Windows 账户分别保存；首次在该电脑配置并保持“记住配置”开启后，后续重启与升级自动恢复。未连接或未选模型时不新增失败评估次数，也不覆盖已保存报告。

如果已经全部作答，但 AI 某轮返回格式错误或等级与依据不一致，页面会显示具体待核对的科目和轮次。点击 **“保留原稿，重试 AI 评价”**，沿用同一份原稿、原音证据与已完成的分科评价，只补未完成科目；无需重答或再次做阿里云评测。回答或原音改变时需正常提交重新评阅；两轮相差至少两档时重新独立评两轮，并阻断旧分歧结果的复用；其他重试只沿同稿连续链保留同一轮次中最近有效的科目，不按高分挑选。普通重新提交或原稿改变会断开这条继承链。全部科目已在同稿历史完成时可直接组成报告，不额外请求 AI；页面明确说明其来源，不称为最新两次整轮盲评。旧原稿、历史尝试和报告保留，重试失败也不清空输入。单次提交最多自动请求一次结构修复，只处理 JSON 或字段形状问题，保留已读出的有效等级；引文、逐项标准和双轮检查仍须通过，不通过则继续待评。

## 入学测评与课程起点

首页的 **“开始 AI 能力测评”** 使用已配置的 AI 生成短测，再通过另一独立请求逐题审查答案、干扰项和原文依据。听力与阅读各含 A1、A2、B1、B2 四层，每层 3 题，合计 **24 道听读题**；另有 1 份自主写作和 1 份自主口语，共 10 组任务。出题须返回全部字段和三个不同事实，审题核对适级且可信的文本误读干扰项，以及包含主体、先行词、限定与因果的完整引证；选项顺序随机化。结构或审题失败时最多修复一次，再重新独立审查，未通过的候选不发布。

听力采用已核验的本地原音与对应原稿，页面保留真人／合成来源区别。A1／A2 入学探测只用已登记且内容版本匹配的日常对话、公告和操作说明，不使用古典寓言或历史文学朗读代替基础日常情境；高阶选材也优先当代社区或学习情境。此登记是来源与语体选择，不是考生难度标定，原音和内容仍需通过哈希审计。测评期间不提供翻译、答案或词典帮助。

完成原始回答后，服务逐题核对听读，并以两轮独立盲评请求核对四项证据。保存实际模型、提示版本、各轮引文与缺项；可使用已配置的第二模型，同一模型双轮会明确标识。相邻一档的差异保留观察范围，以低置信度按较低阶段安排，并由后续新任务复核；相差至少两档、缺失回答、音频证据不足或服务失败保持待评，不能凭空补分或采用高分。真的不会可以明确选择“不会”，与接口失败区分。

写作提示 `placement-2026-10-25-v5`、量表概述 `placement-cefr-writing-2020-v2` 按[欧洲委员会 CEFR Companion Volume（2020）](https://rm.coe.int/common-european-framework-of-reference-for-languages-learning-teaching/16809ea0d4)印刷页66、68的书面表达量表区分基础短测与完整 Academic 作文。先核对固定标准、实际引文和信息间关系，再给出阶段；多段、稀有词或多角度论证不成为 A2／B1 的额外门槛，等级与依据矛盾仍保持待评；v5明确传给模型已有的阶段正向依据校验映射，不改变评分门槛。格式错误最多自动修复一次。此前v4冻结三稿的真实服务对照中，v4 仅一稿取得完整双轮结果，另两稿仍待评，不能据此宣称评分偏低已彻底解决，详见[产品走查报告](产品走查报告.md)。

## 六小时怎样使用

常规参考分配为词汇 45、语法 30、听力 75、阅读 60、口语 60、写作 75、复盘 15 分钟。它们是预算建议，**不是每项必须坐满的最低时长**。10 分钟已完成当前课的全部交付、必要评阅与复盘，且时间足够，下一课自动加入当天必学队列；不会靠等待计时凑完成状态，也不会只因速度快跳过掌握检查。

系统记录真实活动时间，排除暂停、后台停留和 AI 等待。真实学习加已发生的番茄休息累计到 360 分钟后保存当前输入并暂停，下一天可续做。默认继续最早未完成课程，不因日历走到下一天就跳过旧课。新课程按真实交付、评阅和错题复盘判断完成，手填数量不能代替作品。旧日程继续保留原单位和原自报规则，旧打卡不会变成已验证掌握。

**当天课程量会动态变化。** 首页明确给出当前必做单元、后续预告与预计用时。核心尚未提交时优先继续对应原稿，完成各模块后集中订正和复盘；核心原稿齐全后再优先处理错题。评阅待处理时可做其他合适任务，不能把待评算成通过。明确选择的课程课次会保留，旧课错误与待评继续在历史入口核对，选课不补造旧课完成或掌握。后续新单元按同技能、级别、任务类型的真实完整作品预估耗时；至少3份独立样本后用保守分位并留余量，样本不足使用课程预计。详细依据可展开查看。

**剩余时间不足就结束当天任务。** 例如已用340分钟、剩20分钟，完成本课后不会再开启下一课：新课至少预留一轮专注及必要休息。当前课可在剩余时间完成的短尾项仍可继续；未完成内容保存到下一天，不为填满时间挑后置短题。已经开始的输入不会因自动推荐被覆盖或跳走。

**右下角番茄钟**可自行开启，默认专注25分钟、短休息5分钟，每4轮长休息15分钟，均可调整。收起时不挤占页面右侧宽度；仅在足够宽的窗口展开时为内容区预留位置，导航保持全宽。较窄窗口及放大页面时，展开进入页面布局，输入答案时收起。跨页面继续计时，进入休息时暂停课程媒体并保留输入，休息结束后等待手动继续，不自动开麦或播放。学习证据来自实际作品，番茄专注轮数不代替掌握。恢复备份时暂停计时，同档案清空／恢复后旧页面停止写入并要求刷新。

番茄钟新增 **“结束今日学习”**：先显示确认与取消，取消不改变计时或任务；确认前先核对保存状态，正在录音或保存时先完成该操作。确认后暂停今日学习，保留真实已用预算、已完成作品、草稿与录音，未完成内容下一学习日继续；结束标记不代表任务已完成。需要当天继续时可点 **“恢复今日任务”**，恢复原有剩余预算，不把已用时间清零，也不自动开麦或播放。刷新后保持同一状态。

每个环节只有达到真实完成条件才显示 **“本环节已完成”** 和明确的下一模块入口，例如词汇完成后进入语法。缺材料、待评或错误尚未订正时保留对应状态，不以提交、时长或按钮点击提前宣布完成。

**页面自适应：**按浏览器实际可用宽度排版，支持小窗口和浏览器放大。首页学习说明与六小时时间预算在窄窗口上下排列；更窄时导航换行、进度卡片纵向排列、七步入口改为两列，答题输入与操作按钮随容器缩放。大图表在题目内滚动，不撑宽整页。

当天队列依据真实表现继续提供当前程度的常规材料。学得快不直接升级；已经开始的材料保留，关卡与末期保留卷不拿来提前加量。每日 AI 复盘给出的重点和练法会作用于后续尚未开始的常规学习日，保留调整来源与历史。

同一重点、练法和补强材料在14天内保留同一观察窗口；当日复盘、未解错题和待评照常处理。样本充分且出现明确长期下降时，已保存的每日复盘可依据真实未见材料报告调整后续未开始普通日。不同目标或有证据的新风险仍可调整。

## 词汇、说写与错题

**词汇学习**先显示绑定必学词的词义、音标、例句与读音。每词完成三遍正确英文输入，再做三次独立、非静音的真实跟读录音。只点麦克风、播放示范、静音或重复使用同一段原音不计跟读。低分的真实跟读保留次数和原音，其问题进入统一错题本。

新开课程时，本课新词优先展示，已经在前课安排的词明确标为巩固，重复安排不会伪装成全新内容。例如第2课先显示 friend／happy／room／good，hello／student／class／too 标为前课巩固。新草稿保存显示顺序，刷新续作保持；原始词索引、评估与旧草稿位置不改，没有新顺序字段的旧稿继续原序。首页同时显示实际课文名、主听力材料和首次安排／计划巩固摘要。

核对每遍英文输入后，前两遍正确会继续聚焦同一输入位置；错误保留原答案并选中，便于重输；第三遍正确后定位跟读按钮，不自动开麦。Enter 与点击遵循同一核对流程，输入法组合期间不会误触提交。

随后完成 **补全 → 中文写英文 → 听写** 三轮测试，每轮独立洗牌，作答顺序随草稿保存，刷新不会重新排题。续学优先恢复已经进入后续轮次、留有实际作答的草稿，较新的空白重复稿不会抢走进度；草稿列表仍可逐份恢复。听写需有成功听完的播放记录；拼写按标准英文核对。旧版草稿保留原顺序与原成绩，不能凭旧版通过标记取得新版“三写三读”掌握状态。

**听读与语法**提交原始答案，实际错误自动入本；即使总正确率达到阶段线，仍不会漏掉其中的错题。选项题保留大小写等题意差异，多选须全部且仅选对，填空遵守词数限制。

阅读任务在宽屏将正文与题目并排放置，两侧可分别滚动；窄屏完整堆叠，暂停或切换任务时恢复相应布局，正文节点与选词定位保留。日常答题移除可选依据／错因输入框，旧说明仍在历史数据中；题干字号增加4px。客观反馈明确列出原答、参考答案、原文依据及具体差异，区分漏答、拼写、额外词和词数限制；解释 the UK 的定冠词和 classmates 的复数要求，并接受本题 Mr Wang 的称呼缩写点变体，不放宽主体、题意和多选要求。

听力原文按说话人分行，标明本环节第几份录音及对应题号；A/B 是同一对话中的角色，反复出现不代表新材料。226份合成课程听力已完成角色／停顿审计：217份重建、9份核验后保留，4901段声音、4675处实际静音停顿，解码、哈希与角色声线邻接检查均通过，错误0。详情见[听力角色与停顿审计](curriculum/audio/role-pause-audit.json)；文件审计不代表独立真人听审，学习者完整听音仍以真实播放覆盖判断。

**写作与口语**先保存原稿，再进行真实反馈。未评、服务失败和旧自评属于待评队列，不自动编造成错误或判为正确。明确的负面评阅、带原稿依据的错误和真实低分才进入错题本。原稿、录音引用、评阅与订正来源保留。

课程口语分开保存例文跟读与自己的自由回答。例文参考只去除已经确认的段落标签，不删姓名首字母或正文中的 Class A；旧含标签录音、参考原文和有效证据仍可恢复。示范库当前1269份音频审计通过，本轮新增439段去标记示范并保留旧文件；另有243份独立单词音频，错词示范不再用整句替代。历史“未给出音素原因”等套话只在显示时过滤，具体练法与原评估保留；服务真实返回的词级、音素和其他原始字段保留，未提供的原因不编造。

日常课程不再提供自由表达手填转写框。完成例文前置后，可只提交单独的自由表达原音并保存为待评；原有转写、原音和已提交作品保留，新订正录音不借用父稿旧转写。**当前没有配置自动识别／Omni 听音服务，只有 DeepSeek 与 Ali 朗读诊断不能完成自由表达评分。** 页面提供 AI 设置入口，缺证据时不把例文分数当作自由回答成绩。入学测评的原话填写、原音与确认要求未在本轮取消。

**每日错题复盘**先一次展示当天全部待解决题，填写后整页提交。下一轮只剩仍错或待评的题，已通过项不重复累计；服务暂不可用的题保留输入以便重试。看答案不会删去原错，也不能跳过未通过项完成复盘。当天核心材料完整提交、说写取得真实反馈且错题全部通过后，AI 根据当天材料、首次表现和实际订正进行复盘；新增错误或表现更新会使旧完成状态失效。仅完成部分补充练习不能提前标记全日完成或调整后续日。

口语环节完成与某个词仍待订正分别记录。口语错题可在复盘页直接朗读对应原句，不必返回重做整环节；也可先点击 **“核对已存朗读评测”**，核验当前档案中原错误之后保存、来源匹配的新原音与专业结果。可用归档明确标为本机记录，核对不重新录音或调用评分；足够的已有证据不必重做，低分或缺证据的项继续订正。达标项先显示“待整页核对”，整页提交后才收起。

新订正证据使用 `validationVersion=2`：单词项还须有目标词真实词级明细且过线，无明细、词典覆盖问题保持待核对，整段高分不能代替该词；整段维度项按相应三维训练线核对。首尾标点不会绕过词级检查，内部撇号、连字符和缩写点保留。旧已通过轮次按原版本保留，不追溯补造词级证据；归档核验也保留来源及当时错误快照，后来的新错误不能借旧评估自动消除。服务词典限制不再被当作确定错音自动入本，原始尝试、已存评估和录音仍保留。

英文阅读支持按词悬停查看词义、音标和例句；允许辅助的练习中，本地词条不完整时自动向已连接 AI 补查，失败可显式重试，不推测缺失内容。选中词句后右键打开更详细的语法解释。独立测评禁用帮助，使用过提示的练习保留辅助标记。

14个学习页面限制学习区的复制、剪切、粘贴与文字拖入，正常键入、输入法和选区 AI 查询保留；设置、导入及明确允许的参考字段不受影响。此限制用于减少直接粘贴作答，不是绝对防作弊措施。

## 已实现的学习闭环

- **个人记忆与补强观察**：集成 MIT 许可的 `ts-fsrs 5.2.3`，四项技能独立记录。项目自有受限拟合器用真实作品关联的无辅助跨天回忆拟合8项长期权重，较早日期训练、后续日期留出，与默认及当前参数比较；没有可靠改善就不启用。首次至少观察28天，样本不足列出缺口，模型与回滚历史随记忆档案备份。它不是官方完整Rust优化器，也不把目标记忆率调整称作参数训练。
- **未见材料成效对照**：补强前28天与48小时后至30天的真实新材料分窗，按同标注级别、技能、题型及评阅版本比较，遇下一次同技能调整截断。重复、改名、辅助、待评和保留卷不作提升证据；充分下降观察才触发受保护的后续建议。材料未做考生难度等值标定，前后相关性不证明因果。
- **独立材料与词汇补齐**：现有39份独立材料，包括8篇阅读、16段合成听力、8段真人听力共240题及7种Task 1图表；另将原70个未排课候选编成32词汇组和32组新语境应用题，保留原来源。独立短测不进入常规追加、关卡或末期卷，也不冒充完整40题试卷。
- **评分可靠性**：完整参考稿与逐轮引文保存在私人媒体记录，公开目录只含来源、页码、哈希和官方已公布任务分。真实模型盲评不携带参考分，保留模型、提示角色、偏差与失败缺失，支持交换模型顺序复测。已改用按公开分档描述平衡核对的评分规则，修正阶段目标与绝对Band混用；真实对照有所改善，但误差仍不能忽略，不自动统一加减分。
- **精听**：课程听力中支持 A/B 循环、变速、键盘快捷键、无字幕→关键词→英文→中文讲解，再回原速。字幕须有真实时间轴。任何帮助都保留辅助标记，片段播放不能冒充整段已听。
- **全年安排**：以分科未见材料、延迟保持与先修关卡决定推进，保护已开始日与历史原稿。第 14 天观察操作负担、待评和修改比例；记录不足时不计算虚假的考试成功率。
- **无稿口语**：按介绍、问路、预约及 IELTS Part 1–3 等任务逐轮录音和追问，提示逐渐减少。当前是录完一轮再处理，尚非实时双向语音通话。实际理解语音使用本机或已配置云端ASR，或Omni；ASR仅提供自动文本，不代表完整自由表达的声学能力已验证。
- **写作迁移**：从已有真实评阅中选最多三个有原文依据的问题，先自己修改，再做新句微练习。全部取得目标证据至少 48 小时后，才生成另一道迁移题；学习链与时间由本机签名校验，不提前展示陌生题。签名文件随用户文件夹保留；若未迁移签名文件，旧链需重新验证。

## AI 与语音的边界

| 任务 | 使用的证据与通过方式 |
| --- | --- |
| 单词跟读 | 原音和完整阿里云专业结果；保留独立 work/evidence ID 与非静音校验 |
| 例文跟读 | 分段保存原音，自动专业评测，再给中文练法；原音、参考原文和结果可回看 |
| 基础写作 | 两轮对同一原稿的适级目标核对，需有可核对引文；不强行给 A0 短句出 Band |
| 基础口语 | 已有可核对文字与原音的旧稿可继续核验 Ali 范围证据及两轮阶段反馈；新课程自由回答可只存原音待评，当前无自动识别／听音配置时不判完整通过 |
| 高级／完整口语 | 可选 Qwen Omni 对完整原音逐段观察，保留时间点、覆盖和媒体对应，再由文本 AI 双轮复核 |
| 完整 Academic 写口测评 | 各维度真实证据与两轮训练线；缺音频、缺维度或意见分歧时保持待验证／需补强 |

前期专业训练线使用准确度 80、流利度 75、完整度 90；缺少关键维度不算通过。这些 0–100 指标不能换算 IELTS Band。Ali 对给定文本范围的训练诊断与 Omni 的完整自由表达观察有不同用途。

通用 AI 默认 DeepSeek 地址 `https://api.deepseek.com`、偏好模型 `deepseek-flash`，实际模型以连接后返回列表为准。阿里云采用 AppID/AppSecret 动态授权和刷新；Azure、ASR、Omni 是分别配置的可选服务。没有 Omni 时不能补造完整口语四维证据。

第二评阅模型可复用主连接选择另一可用模型，或配置独立 API；不自动替用户选模型。同一模型双轮仍明确标为同模型，单项分歧达到一分时不取高分，而是保留待验证。评分校准内置三份原创守护样例，也接受用户有权使用的带分样例；原创参考线不冒充官方考官标定。

评分索引现有10份官方带分完整稿。原4份为开发组，新增6份来自两份出版包、三道题（Task 2四稿、Task 1两稿），在新规则冻结后一次性盲评；正文只作私人本地资料，公开索引保留来源、题目入口、页码、图表文字等价输入的局限与哈希。不同出版包不等于独立考官。

真实服务结果：旧四稿上，flash的MAE从1.75降至1.59，pro从1.56降至0.94；新六稿上分别为1.00和0.65，误差在±0.5内分别为2/6和3/6，均无缺分。pro新组平均有向偏差约−0.02，但正负误差会抵消，不能据此称评分准确。两模型与提示轮角色仍有混杂；没有统一加分、选择较高轮或把任务Band补成四维参考。旧规则仅供校准页显式对照，日常作品使用当前规则。

方法见[私人评分参考说明](calibration/README.md)，预先锁定范围见[预注册](calibration/reference-preregistration-v60.json)，逐稿公开数字见[本轮真实服务审计](calibration/service-audit-v60.json)；[0.0.50历史实验](calibration/service-audit.json)保留。

费用默认不限额，用量与预算上限为可选功能。录音结束后的自动专业评测及 AI 反馈会发送对应学习内容到所配置服务。明文密钥和动态 Token 不进入浏览器存储、教材、浏览器导出或 Git；每日完整备份包含按电脑加密的配置密文。

## 备份、资料与离线使用

正式保存位置默认为项目根目录下的 **`用户数据/`**，当前部署为 `\\mynas\family\IELTS_52篇学习包\用户数据`。可用绝对路径环境变量 `IELTS_DATA_DIR` 指向单独的长期存储位置。浏览器只保留工作缓存；首次迁移包括已有各档案的作品、草稿、错题、计划、录音和恢复点，全部保存成功后才登记版本。新浏览器恢复档案完成后才打开课程，避免空缓存覆盖已有进度。

| 子目录 | 内容 |
| --- | --- |
| `config/` | Windows DPAPI 加密的服务配置与保存开关（按电脑和账户存于 `credential-owners/`）、用量账本、写作学习链签名文件；`placement/` 单独保存按档案绑定的测评题目、私有答案、原稿与评估依据 |
| `profiles/` | 各档案快照、当前及最近三份历史版本、发生冲突时保留的候选 |
| `blobs/` | 按 SHA-256 保存的原始录音与恢复点中的二进制附件 |
| `materials/` | 新导入个人资料，以及原 41 份教材和目录、封面的校验副本 |
| `backups/daily/` | 最近 30 个备份日的完整备份清单、去重附件及最近一次恢复前的安全副本 |
| `runtime/`、`logs/` | 自动安装的本地 Node.js 与启动故障日志 |

用户目录整体被 Git 忽略，不能通过普通静态网页路径读取。学习数据先保存附件，再原子提交快照；并发修改采用版本核对，冲突时保留两份，用户可在备份中心选择恢复文件夹版本或继续保存浏览器版本。写盘失败会显示未同步状态并保留本机数据；只有明确显示已保存才算写入成功。`preview=1` 继续隔离，不写正式用户文件夹。

**读取与保存默认自动进行。** 0.0.62 起，档案检查不再扫描全部教材；浏览器启动只完整核对本地档案一次，版本未变就省去远端快照传输。页面脚本在档案核对时并行预取，通过保护屏障后按原顺序执行；已核对的待同步草稿可先打开学习页，再后台保存。重复写入被合并，普通保存不弹黄色提示；短暂断网或共享锁忙会自动退避重试，真正失败仍显示原因。不会用空缓存、损坏文件或较旧版本覆盖有效数据。

**每日完整备份：** 当天课程的核心任务、订正与复盘真实完成后，自动在后台额外备份所有档案、配置、进度、作品、原音和个人资料，包含入学测评的私有报告与评估依据。同一天完成更多课程或更新作品时更新同一份；仅再次浏览旧的已完成课程不会占用新的备份日。保留最近 **30 个有备份的日期**，新备份写入并校验成功后才清理最早一份；相同教材和录音按内容去重，不重复复制 30 份。未完成请求保留到下次重试。备份中心提供“立即备份”和按日期完整恢复，恢复前检查内容哈希、并发版本及写入锁，保留恢复前安全副本，当前电脑的服务随后自动重新连接。恢复失败或重连状态未知时，不提前显示“已恢复”。

完整备份保留加密配置原件，不导出明文密钥；阿里云临时 Token 不落盘，恢复服务后按需重新获取。运行环境、日志和备份自身不递归纳入备份。完整恢复会影响共享目录内的所有学习档案和配置；恢复时应结束其他电脑的学习服务，恢复后从最新版启动器重开，以重新载入其内存中的 AI 配置。Windows 加密配置通常只能由原电脑、原账户解密。备份同样位于 NAS，不能替代 NAS 本身的异机或离线备份。

**NAS共享使用：**每台电脑双击同一共享文件夹中的“启动学习.cmd”，都在该电脑启动自己的 `127.0.0.1` 服务；用户文件夹仍位于NAS，保存依赖共享连接和写入权限。共享代码升级不会自动替换各电脑内存中的旧服务。0.0.61起启动器核对实际运行代码，重新双击时只更新经本机端口、进程归属和完整项目路径验证的旧学习服务；不处理其他项目或无法确认的进程。健康信息固定为进程启动时的版本，不再把磁盘的新版本误报为已运行版本。

出现“写入未完成”时，先保留原学习页面，在**出现提示的那台电脑**重新双击启动器；服务就绪后回原页点“重试保存”。新页面也可点“重新读取”。提示条与备份中心现在显示具体原因和错误编号，查看状态会另开标签，不带走正在学习的页面。新页面识别不支持其数据模块的旧服务时，停止向它提交，保留缓存并给出更新步骤。共享保存锁刚创建、写入中或刚释放的短暂状态会等待重试，不误报档案损坏；其他电脑持有的锁不会被擅自删除，同档案不同版本仍保留双方。

开发验证使用 `preview=1`、临时测试目录，或在开发电脑设置独立的 `IELTS_DATA_DIR`（例如 `用户数据/开发测试` 的绝对路径）及 `IELTS_PORT=8766`，避免开发操作写入家人的正式档案。此举隔离测试数据；共享代码本身仍会随开发变化，家人使用新版本前需重新双击启动器。长期并行开发可进一步采用独立的稳定发布目录。
