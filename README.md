# IELTS Learning · 52 周 Academic 自学

当前版本：**0.0.20**（见 [VERSION](VERSION)）。

面向成人零基础学习者的本地电脑学习软件。按 52 周、364 天、每天 360 分钟组织，以 Academic 听说读写各 7.0 为内部训练目标，为正式考试各 6.5 留出余量。学习量、独立能力证据、AI 估计与正式成绩分别记录；完成日程不能保证考试分数。

## 开始使用

1. 安装 Node.js 22 或更新版本，双击 **启动学习.cmd**。
2. 打开 `http://127.0.0.1:8765/`，进入 **完整课程**，从第 1 天开始；在 **每日学习计划** 设置开课日期。
3. 如需 AI 反馈，进入 **AI 设置**，分别连接通用 AI 与语音评测服务。
4. 定期在 **备份中心** 导出文字记录；原始录音另用页面的录音备份功能导出。

核心材料、题目、答案、图表、已生成音频和教材保存在本地。AI、语音评测和在线转写需要联网。建议统一使用上面的本机服务地址：file://、localhost、127.0.0.1 和不同端口的浏览器记录互不共享；部分浏览器还会限制直接打开 NAS PDF。

## 课程和掌握证据

全年内容由 508 份原创听读写源材料、8 个基础听辨专项、2 个听力平面图专项，以及派生的词汇、语法、说写和复盘任务构成。本轮正式构建为 `complete-material-set`，源材料与音频缺项均为零。

| 已验收内容 | 数量 |
| --- | ---: |
| 学习日／计划有效学时 | 364 天／2184 小时 |
| 源材料、派生练习与每日复盘合计 | 1380 项 |
| 课程中可判分的客观题（含语法专项） | 6160 题 |
| 已生成并核对文本版本的听力音频 | 210 份 |
| 完整题量阅读／听力 | 各 30 套 |
| Academic Task 1／Task 2 题目合计 | 124 题 |

完整题量统计包括训练、关卡和末期卷，不能把派生任务数理解为同等数量的独立课文。第 4–48 周共有 12 组 A/B 关卡；第 49–52 周另有四套保留末期卷，通过近期三套独立表现核对准备度。详见 [覆盖检查](curriculum/coverage.json) 与 [发布验收](curriculum/release-audit.json)。

- 第 1–8 周：48 篇短阅读、48 段听力，另有字母、数字、最小音对、重音、词尾和连读听辨。
- 第 9–20 周：48 篇分级阅读、48 段情境听力，以及适级口语和段落写作。
- 第 21–36 周：48 篇过渡阅读、64 个听力分节任务；常规 Task 1、Task 2 各 32 题，覆盖表格、折线、柱图、饼图、地图、流程和组合图。
- 第 37–48 周：12 套完整题量训练；第 49–52 周：4 套保留末期材料。另有阶段 A/B 包，早期适级、后期完整题量。

原创材料经过规则校验、未提供标准答案的第二轮 AI 解题及针对性审查。它们使用模拟场景和数据，未经真实考生难度标定，不能将正确率直接换算官方 Band。合成听力提供英、美、澳音色及对话角色；不是教材原版录音，也不代表正式听力的真实语速与考试长度。

每日任务绑定材料与提交物。客观题按“题”、词汇按“条”、说写按“词”、复盘按“份复盘”累计；实际活动计时排除暂停和后台停留，不自动补齐六小时。旧日程已有自报数据继续按旧单位显示，不改成新的客观证据。

原稿不能被订正覆盖；帮助标记、曝光、原始答案和音频引用会保留。查看过同题再开始，不会重新成为“未见”。阶段 A 卷合格后，还需至少间隔 48 小时使用 B 卷复测。最后准备度要求近期三套不同日期的完整未见任务，听读各至少 32/40，写口各维度有两轮 7.0 训练估计及证据；缺少音频评价时发音保持待验证。

零基础关卡核对适级表达目标，不要求初学者获得 Band 7。未达标时安排订正、新情境迁移和延迟复测，必要时延长学习周期。详见 [开发规划](开发规划与资料清单.md)。

## AI 与语音配置

**通用 AI** 默认地址为 `https://api.deepseek.com`、偏好模型 `deepseek-flash`。输入密钥并确认后获取实际模型列表，再选择、验证。AI 用于词句语法详解、写作和口语文字反馈；文本模型不会凭转写判断真实发音。

**语音评测** 默认提供阿里云 AppID、AppSecret 填入项。保存后经正式 HTTPS 接口动态申请 Token，评测前在到期缓冲期刷新，失效时仅刷新重试一次，无需手动续填临时 Token。用户 ID 与出口 IP 可在高级选项调整。朗读的发音、流利度和完整度为专业服务的 0–100 指标，不能换算 IELTS Band。

高级选项保留 Azure Speech、千问 ASR 和 Qwen Omni。ASR 只负责可编辑转写；Omni 按片段分析完整原音，保留时间点与证据覆盖，再将观察送给文本 AI 双轮复核。缺失片段、无效证据或未配置服务时，相关声学维度不出分。完整口语 AI 估计仍可能误判，需要回听核对。

密钥和动态 Token **仅驻本地服务内存**，不写浏览器存储、教材、项目文件或 Git。关闭或重启服务后需重新输入。费用不设默认上限；可选账本在被 Git 忽略的 private/ 下，不记录学习正文、录音或密钥。真实费用以服务商账单为准。

## 划词、语法和听写

在英文课文或课程练习正文中左键选中词句后点击右键，即发送选区与有限上下文，获取中文词义、逐词说明和语法拆解；也可使用浮动按钮或 Alt＋Enter。支持追问、收藏、反馈错误、结构化迁移小题和延迟回忆。独立测评中禁用 AI 详解，使用过帮助的作品不会作为无辅助证据。

原 52 篇课文保留 156 个语法点、312 道配套题、逐句听写、360 张词卡及原有离线音频。它们是补充练习，不替代全年课程。词卡采用透明固定间隔规则，并非 FSRS。

## 本地教材

从用户指定的 `\\mynas\family\教材` 导入 42 个 PDF，按 SHA-256 去重保留 41 份原件，约 2.35 GiB。已核实 64 套试卷起始位置和相关页码；剑桥 12 保留原书 Test 5–8 编号。含不同版本和解析，不能把所有文件自动视作 Academic 真题。

保留末期卷默认折叠，打开正文或答案会登记曝光，后续自报“未见”不会抹去历史。目录中未发现配套听力音频，页面明确标记缺音频。教材由用户授权随代码上传，PDF 与新课程 MP3 通过 Git LFS 保存；未给第三方教材另行授予开源许可。详见 [教材库说明](materials/教材库说明.md)。

## 备份与档案

文字作品和录音使用浏览器 IndexedDB，偏好与部分旧记录使用 localStorage。不同学习档案相互隔离；切换档案后旧页面不能误写新档案。备份导入先校验、检查冲突，再合并；写入失败尝试回滚，不覆盖损坏的原始数据。录音体积较大，使用单独的媒体备份。浏览器清理数据、换设备或入口前先导出。

`preview=1` 供功能验证，使用独立预览数据，不应作为正式学习入口。
