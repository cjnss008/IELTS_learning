# IELTS Learning · 52 周 Academic 自学

当前版本：**0.0.43**（见 [VERSION](VERSION)）。

面向成人近零基础学习者的本机自学软件。课程覆盖 **52 周核心课程与第 365 天年度复盘**，以听说读写各 7.0 为内部训练目标，为正式考试各 6.5 留出余量。每天 6 小时是总可用预算，材料学会后立即继续；时间、重复题正确率和 AI 估计都不是考试成绩保证。

## 开始使用

1. 双击 **启动学习.cmd**。启动器先检测 Node.js；缺少合适版本时自动把随包附带、校验过的运行环境安装到用户文件夹，无需管理员权限或手动设置 PATH。服务就绪后打开统一首页，成功时启动窗口自动关闭；失败时显示错误并保留窗口。
2. 每天从 **[今日学习](今日学习.html)** 继续，按词汇、语法、听力、阅读、口语、写作、错题与复盘的顺序进入具体材料。
3. 在 **AI 设置** 分别配置 DeepSeek 和阿里云专业语音服务。Windows 默认加密保存到用户文件夹，重启自动恢复；也可关闭持久保存，仅保留本次服务连接。学习资料、已有音频和原稿可本地保存；需要真实评阅的项目在服务未就绪时保持待评。
4. 首次开始学习时自动设置开课日期，也可在 **52 周进度** 调整。**备份中心**显示用户文件夹路径、保存状态、恢复点与个人资料入口。升级时保留整个用户文件夹；仍建议定期额外备份。

统一服务地址为 `http://127.0.0.1:8765/`。请通过启动器使用，直接打开 HTML 文件不能访问用户数据服务。新版在启动课程前先读取文件夹档案；首次升级请从原浏览器、原地址打开一次以迁移旧缓存。多个浏览器有不同修改时停止覆盖并保留冲突候选。

## 六小时怎样使用

常规参考分配为词汇 45、语法 30、听力 75、阅读 60、口语 60、写作 75、复盘 15 分钟。它们是预算建议，**不是每项必须坐满的最低时长**。10 分钟已完成当前材料并取得相应证据，就继续下一份；不会靠等待计时凑完成状态。

系统记录真实活动时间，排除暂停、后台停留和 AI 等待。当天累计到 360 分钟后保存当前输入并暂停，下一天可续做。默认继续最早未完成课程，不因日历走到下一天就跳过旧课。新课程按真实交付、评阅和错题复盘判断完成，手填数量不能代替作品。旧日程继续保留原单位和原自报规则，旧打卡不会变成已验证掌握。

当天有剩余预算时，追加队列优先核对未完成或待验证的内容，再依据真实表现提供当前程度的常规材料。学得快不直接升级；已经开始的材料保留，关卡与末期保留卷不拿来提前加量。每日 AI 复盘给出的重点和练法会作用于后续尚未开始的常规学习日，保留调整来源与历史。

## 词汇、说写与错题

**词汇学习**先显示绑定必学词的词义、音标、例句与读音。每词完成三遍正确英文输入，再做三次独立、非静音的真实跟读录音。只点麦克风、播放示范、静音或重复使用同一段原音不计跟读。低分的真实跟读保留次数和原音，其问题进入统一错题本。

随后完成 **补全 → 中文写英文 → 听写** 三轮测试。听写需有成功听完的播放记录；拼写按标准英文核对。旧版草稿保留原顺序与原成绩，不能凭旧版通过标记取得新版“三写三读”掌握状态。

**听读与语法**提交原始答案，实际错误自动入本；即使总正确率达到阶段线，仍不会漏掉其中的错题。选项题保留大小写等题意差异，多选须全部且仅选对，填空遵守词数限制。

**写作与口语**先保存原稿，再进行真实反馈。未评、服务失败和旧自评属于待评队列，不自动编造成错误或判为正确。明确的负面评阅、带原稿依据的错误和真实低分才进入错题本。原稿、录音引用、评阅与订正来源保留。

**每日错题复盘**先一次展示当天全部待解决题，填写后整页提交。下一轮只剩仍错或待评的题，已通过项不重复累计；服务暂不可用的题保留输入以便重试。看答案不会删去原错，也不能跳过未通过项完成复盘。当天核心材料完整提交、说写取得真实反馈且错题全部通过后，AI 根据当天材料、首次表现和实际订正进行复盘；新增错误或表现更新会使旧完成状态失效。仅完成部分补充练习不能提前标记全日完成或调整后续日。

英文阅读支持按词悬停查看词义、音标和例句；选中词句后右键打开更详细的语法解释。独立测评禁用帮助，使用过提示的练习保留辅助标记。

## 本轮新增的学习闭环

- **分技能记忆**：集成 MIT 许可的 `ts-fsrs 5.2.3`，认义、拼写、听辨和语境表达独立记录。同日反复作答与提示后答对不抬高长期保持；新的错误会收回免重复资格。算法目前使用默认权重与个人答题历史，尚未用长期个人数据拟合参数。7／30 天负担仅估计当前卡片首次回忆量，不是未来全部复习的模拟。
- **精听**：课程听力中支持 A/B 循环、变速、键盘快捷键、无字幕→关键词→英文→中文讲解，再回原速。字幕须有真实时间轴。任何帮助都保留辅助标记，片段播放不能冒充整段已听。
- **全年安排**：以分科未见材料、延迟保持与先修关卡决定推进，保护已开始日与历史原稿。第 14 天观察操作负担、待评和修改比例；记录不足时不计算虚假的考试成功率。
- **无稿口语**：按介绍、问路、预约及 IELTS Part 1–3 等任务逐轮录音和追问，提示逐渐减少。当前是录完一轮再处理，尚非实时双向语音通话。实际理解语音需要已配置的 Omni 或 ASR；只有 DeepSeek 与阿里云朗读评测时不能伪装已听懂自由表达。
- **写作迁移**：从已有真实评阅中选最多三个有原文依据的问题，先自己修改，再做新句微练习。全部取得目标证据至少 48 小时后，才生成另一道迁移题；学习链与时间由本机签名校验，不提前展示陌生题。签名文件随用户文件夹保留；若未迁移签名文件，旧链需重新验证。

## AI 与语音的边界

| 任务 | 使用的证据与通过方式 |
| --- | --- |
| 单词跟读 | 原音和完整阿里云专业结果；保留独立 work/evidence ID 与非静音校验 |
| 例文跟读 | 分段保存原音，自动专业评测，再给中文练法；原音、参考原文和结果可回看 |
| 基础写作 | 两轮对同一原稿的适级目标核对，需有可核对引文；不强行给 A0 短句出 Band |
| 基础口语 | 当前新原稿与新原音的阿里云范围证据，加两轮带原稿依据的阶段反馈；不冒充完整自由口语评分 |
| 高级／完整口语 | 可选 Qwen Omni 对完整原音逐段观察，保留时间点、覆盖和媒体对应，再由文本 AI 双轮复核 |
| 完整 Academic 写口测评 | 各维度真实证据与两轮训练线；缺音频、缺维度或意见分歧时保持待验证／需补强 |

前期专业训练线使用准确度 80、流利度 75、完整度 90；缺少关键维度不算通过。这些 0–100 指标不能换算 IELTS Band。Ali 对给定文本范围的训练诊断与 Omni 的完整自由表达观察有不同用途。

通用 AI 默认 DeepSeek 地址 `https://api.deepseek.com`、偏好模型 `deepseek-flash`，实际模型以连接后返回列表为准。阿里云采用 AppID/AppSecret 动态授权和刷新；Azure、ASR、Omni 是分别配置的可选服务。没有 Omni 时不能补造完整口语四维证据。

第二评阅模型可复用主连接选择另一可用模型，或配置独立 API；不自动替用户选模型。同一模型双轮仍明确标为同模型，单项分歧达到一分时不取高分，而是保留待验证。评分校准内置三份原创守护样例，也接受用户有权使用的带分样例；原创参考线不冒充官方考官标定。

费用默认不限额，用量与预算上限为可选功能。录音结束后的自动专业评测及 AI 反馈会发送对应学习内容到所配置服务。密钥和动态 Token 不进入浏览器存储、教材、备份或 Git。

## 课程覆盖与题目质量

`curriculum/coverage.json` 当前为 `complete-material-set`。本轮新增第 37–52 周每周一读一听共 **32 份独立原创源**、**3 份 NOAA 原声材料**，并把前 36 周已编写但未训练的 446 个词条补进小组日程。后期同一材料跨日重复会标为计划巩固，个人是否见过另按实际曝光判断。

课程覆盖页区分源文章、派生练习、词形、释义标签、明确词族和真实学习证据。实际词汇覆盖为 **1616 个排课词形**，相对原 667 个增加 949 个；共有 360 个搭配，仍有 70 个常规候选未排课，清单公开保留。词形数不等于词族数，也不能据此宣称达到某个 IELTS 词汇水平。数量、文件哈希及完整覆盖见 [覆盖检查](curriculum/coverage.json)、[新增内容审计](curriculum/growth-audit.json) 与 [发布验收](curriculum/release-audit.json)。

NOAA 三份材料保留官方来源、适用许可说明和原音文件哈希。Deep Ocean 使用官方 VTT；另两份只有官方转录，可手动设 A/B，不伪造逐句时间轴。原创声音明确标为合成；原声材料不能代表完整多口音题库。

当前课程编号为 **1–365**；第 365 天单独汇总全年作品、分科证据与下一阶段缺项。第 4–48 周有 12 组 A/B 关卡；A 卷之后至少间隔 48 小时，再用未曝光 B 卷复测。第 49–52 周另有四套保留末期材料，近期准备度要求三套不同日期的完整证据。基础桥梁、重复题和原 52 篇短文不能替代陌生完整测评。

保留上一版 120 道不同题的 Codex 内容核对记录，本轮另由独立子智能体对 13 份新增源、104 题逐题对照原文，修正容量与实际数量混淆、中位数答案范围、英美单位拼写及数字答案漏收，并扩大核对同类数量题。规则审计与抽查范围见 [题目质量报告](curriculum/question-quality-audit.json) 和 [产品走查](产品走查报告.md)。这不是全题库逐题真人审核，也没有完成真实考生难度标定。

原创场景、合成声音和材料数量不能保证学习效果。先通过 14 天试学检查操作与难度，再观察 4–8 周未见题、延迟保持和辅助依赖；52 周结果需要实际长期表现支持。第 365 天不会自动认定达到目标；证据不足时继续补强并明确需要延长的项目。

## 备份、资料与离线使用

正式保存位置默认为项目根目录下的 **`用户数据/`**，当前部署为 `\\mynas\family\IELTS_52篇学习包\用户数据`。可用绝对路径环境变量 `IELTS_DATA_DIR` 指向单独的长期存储位置。浏览器只保留工作缓存；首次迁移包括已有各档案的作品、草稿、错题、计划、录音和恢复点，全部保存成功后才登记版本。新浏览器恢复档案完成后才打开课程，避免空缓存覆盖已有进度。

| 子目录 | 内容 |
| --- | --- |
| `config/` | Windows DPAPI 加密的服务配置、保存开关、用量账本、写作学习链签名文件 |
| `profiles/` | 各档案快照、当前及最近三份历史版本、发生冲突时保留的候选 |
| `blobs/` | 按 SHA-256 保存的原始录音与恢复点中的二进制附件 |
| `materials/` | 新导入个人资料，以及原 41 份教材和目录、封面的校验副本 |
| `runtime/`、`logs/` | 自动安装的本地 Node.js 与启动故障日志 |

用户目录整体被 Git 忽略，不能通过普通静态网页路径读取。学习数据先保存附件，再原子提交快照；并发修改采用版本核对，冲突时保留两份，用户可在备份中心选择恢复文件夹版本或继续保存浏览器版本。写盘失败会显示未同步状态并保留本机数据；只有明确显示已保存才算写入成功。`preview=1` 继续隔离，不写正式用户文件夹。

升级代码时保留 `用户数据/`；复制项目到新位置时同时带走该文件夹，或让新程序继续使用同一个 `IELTS_DATA_DIR`。程序升级不会主动清空它。加密密钥受 Windows 当前账户约束，换电脑或 Windows 账户后可能需要重新输入服务密钥；这不影响文字与录音资料的保留。

旧版 `%LOCALAPPDATA%\IELTS Learning\credentials.dpapi` 以及旧用量、签名文件会复制并校验到新目录，迁移不删除旧文件。阿里云动态 Token 仍只在内存，到期自动重新申请。关闭“记住配置”保留明确的停用状态，重启不会擅自开启。

备份中心继续提供文字及音频导出、严格校验合并、档案切换和“清空进度，保留 AI 配置”。清空前先保存恢复点，清空／恢复期间禁止旧页回写；恢复点也进入文件夹快照。文件夹解决升级与浏览器缓存变化造成的进度丢失，磁盘损坏仍需依靠另外保存的备份。
本地教材为用户授权导入的 41 份不重复 PDF，保留末期卷折叠和曝光记录；目录未提供的配套听力不假装存在。初次升级会在后台逐份复制教材至用户目录，验证大小和 SHA-256；中断后重试，原件保留，旧教材链接继续可用。个人资料单份上传上限 128 MiB，已有大教材通过文件迁移保留。PDF、新课程音频、词音、示范音频及运行环境压缩包按 `.gitattributes` 通过 Git LFS 管理。第三方教材未因随项目保存而获得另行开源授权。
