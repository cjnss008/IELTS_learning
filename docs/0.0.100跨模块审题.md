# 跨模块题目线索检查：开发候选

此工具只检查独立目录中 `active:false` 的普通课件待审包，不改变课表、材料或用户档案，不生成学习记录或成绩。它校验包中声明的 JSON 内容哈希后，报告听力、阅读题可能提前出现的字面线索：词卡引用、排在前面的模块正文、音频转写和题干选项、本题题干，以及其他题干和选项。

```powershell
node tools/audit-linked-teaching.cjs 路径/release-proposal.json
```

结果输出到标准输出，附待审包 SHA-256；使用者可另存至独立开发工作区。只对可信、独占的公开课件快照运行，不要指向用户数据目录。路径越界、链接、超过大小上限、材料哈希不一致或词卡例句与所引用原文不一致会报错。包自身声明的哈希只能检查一致性，不能验证作者、授权或签审；并发改写也不能仅靠文件时间和自声明哈希排除。单份材料超过提示或比较预算会明确标为未完成。当前仅接受原文词形与词卡词头一致的候选；其他词形须先做可追溯的词形核验，不能凭空补全。它不连接网络，也不读取 AI 或语音设置。

这只是启发式线索，**出现提示不一定是泄题，无提示也不代表审题通过**。人名、常见词或其他题干扰项可能造成误报；改写、同义表达、人物关系及未收录字段会漏报。模块顺序是计划顺序，不证明某个使用者实际已经接触前置材料。当前只检查题面、词卡引文和有限正文，并不判断题目难度、选项是否唯一、语法解释、素材权利、美音、音频质量、用户掌握情况或雅思成绩。

口语也不能按未显示的字段计题量。固定的 98 公开材料快照中，145 份口语材料含 `parts` 字段，其中 53 份至少一条 `parts` 文本未在 `prompt` 中逐字出现。当前 Player 显示 `prompt`、`instructions` 和朗读例文，AI 评阅请求使用 `prompt`（为空时使用 `instructions`），不使用额外 `parts`。这是字面盘点，语义可能重合，也没有核验实际排课或用户是否接触；不等于 53 份已使用材料缺题。新材料应以真实显示的题面计数，必要时为未开始的内容另建可追溯版本。

第 2 课旧版中，`week` 卡片直接呈现听力 Q3 的原句、`homework` 卡片直接呈现 Q5 证据；已交作者另建新版本。第 5 课阅读的 Maya 和第 11 课听力的 Nora 也被提示，但词卡只是在别的情境中提到名字，需逐题阅读上下文，不能自动判为泄题。修订前后须保留旧题与原答案，并重新核对版本和哈希。

工程测试使用合成材料及独立候选；真人听音、真实用户档案和浏览器验收不在此工具范围内。
