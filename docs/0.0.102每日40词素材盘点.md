# 每日 40 词：全年素材开发盘点

此工具是只读的课件制作辅助，不修改页面、课程、AI 配置或学习记录。它只读取经过固定哈希校验的 0.0.98 公开课程快照及其年度索引，不读取用户档案、录音或凭据。应在可信、独占的开发快照上运行；不要把输出重定向到用户数据目录。

```powershell
node tools/build-annual-linked-supply.cjs --root . --daily-target 40
```

省略 `--daily-target` 时仍按原来的 30 词目标盘点；可加 `--full` 向标准输出列出逐日候选、来源哈希及原文坐标。只允许目标 30 或 40，不接受输出文件路径。

对固定公开快照，从第 2 至 365 课按听读正文的字面词头匹配，并按其他模块的字面重合数、参考词频贪心选择且不重复：

- 每日目标 40 的一次盘点共选出 **3,646** 个不同候选，**19** 课找到 40 个候选；364 个课位总计有 **10,914** 个候选缺口。全部 **3,755** 个不同字面输入候选未必都会被此贪心分配选中。
- 每日目标 30 的独立盘点共选出 **3,556** 个候选，**35** 课达到 30 个，累计缺口 **7,364**。两个目标在早期课位的分配不同，不能把这两个盘点的每日数量当作同一份课表的直接对照。
- 第 2–365 课若每天 40 个彼此不同的新词，需要 14,560 个词头位置；现有参考表为 8,000 词头，假设这些词都未学过且均可使用，算术上至少还需 6,560 个不同词头。词表条目不等于已配有合适语境、词义、词音或练习。
- 第 365 课原有年度复盘；盘点只确认静态入口，未核验其运行时先修条件或任何用户的完成状态。独立测评和保留材料不用于候选。

所有候选均标为义项待审核、个人新旧未知、未掌握。旧作答、旧草稿、到期复习、当天时间、音频许可及实际内容难度需要分别核查。字面匹配和贪心缺口既不是最佳分配证明，也不是学完后 IELTS 成绩的证明；到期复习不以词数或本工具结果截断。

已有第 2–16 课和第 169 课的若干独立素材候选尚未作为完整课程启用。新增内容与原公开计划、家人档案及每日预算的兼容验证、真人音频试听与真实浏览器验收仍待完成。具体工程测试见[验证记录](validation/v0.0.102.json)。
