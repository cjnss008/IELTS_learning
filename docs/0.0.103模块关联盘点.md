# 词汇与其他学习模块的关联盘点

全年素材开发工具在既有 `--daily-target 30|40` 盘点中增加 `literalLinkage` 汇总。它只检查固定公开快照中普通训练材料的字段，不读取用户配置、原答、录音或个人进度，也不改变课程。运行方式和候选选择规则见[每日 40 词素材盘点](0.0.102每日40词素材盘点.md)。

```powershell
node tools/build-annual-linked-supply.cjs --root . --daily-target 40
```

这次 40 词贪心盘点选出的 3,646 个不同词头候选中，286 个在至少两个技能的文本字段有相同词形，119 个同时在阅读与听力字段有匹配，10 个在阅读、听力、语法、口语和写作的选定字段中均有匹配。364 个课位中，53 个课位至少有一个候选同时在听读出现，1 个课位至少有一个候选在五种字段出现。

这些数值只表示**所选来源中的字面匹配**，不是对全年课程是否真正关联的完整判定。匹配可能是不同词义或词性，语法字段出现同一词也不等于有相关语法讲解；相反，屈折形式、同义表达或语境关系可能被漏掉。口语字段仅检查题干及现有参考，写作字段仅检查题干；不能把这当作用户已完成练习或会在真实页面看到全部材料。

工具同时统计原课表是否列出六类任务、静态普通材料是否包含相关字段。独立测评日和第 365 天年度复盘会计入原始统计，缺少普通训练字段不自动意味着缺陷；不能把测评答案提前加入训练来凑数。真实显示、学习起点、待办、预算和 AI 调整均以运行时核验为准。

该工具不提供课程签审、真人语音试听、数据迁移或 IELTS 成绩证明。新材料仍需逐词核对语义和声源，逐题检查、与既有作答和复习兼容，再进行真实页面验收。工程测试见[验证记录](validation/v0.0.103.json)。
