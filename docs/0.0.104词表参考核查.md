## 来源与口径

2026-10-28 将[公开的 2014 年第三方词汇索引](https://ielts.koolearn.com/20140411/785955.html)与项目固定公开词汇目录比较。工具按索引发现的 26 个字母页及首页可见的分页范围读取；网站内容或分页方式以后可能改变。该第三方词表并非雅思官方 7 分必备词表。[IELTS 官方写作评分描述](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)按任务完成、连贯衔接、词汇和语法等维度评分，不能用词表数量代替评分。

固定的项目词汇文件有 8,000 个不同标准化词头，SHA-256 为 `bf0f6fe5b623a9e5d5a37df16cda1a2a0c1c9ff73b76ed6318d45cc546eb8079`。本次读取 127 个文章分页（26 个首屏、101 个后续分页），所有请求成功；8,012 个段落中有 34 个非空段落未能按词条规则解析。解析得到 7,946 个不同词形：5,976 个与目录标准化词形完全一致，1,970 个不完全一致。未解析行、词形变化、短语、大小写标准化和多个词义等会影响结果；不能把后者直接解释为实际缺少 1,970 个词。

匹配不说明词义适合该课、在听读中有足够语境、材料已讲授、学习者首次接触或已经掌握。已抓取的分页不保证源站没有隐藏在其他入口中的内容。网页原文和词表不写入项目；只输出汇总，`--full` 额外输出页地址、段落数及网页 SHA-256，不输出词或释义。

## 开发者运行

在与上面哈希一致的公开快照根目录，使用 Python 3 和 Node.js：

```powershell
python -B tools/audit-ielts-reference.py --root .
python -B tools/audit-ielts-reference.py --root . --full
python -B tests/ielts-reference-audit.test.py
```
