# 0.0.107 发布范围与后续工作

本次按用户要求提前合并稳定修复。它解决学习痕迹、词汇完成提示和备份导入误报；不将未启用的全年关联课件当作已交付。

## 家人能使用的改动

- 词汇模块汇总本课全部词组的提交状态、完成状态和学习次数，全部处理后提供整体确认与继续入口。
- 已提交原稿保留原答案与成绩；“重新学”单独保存练习。未提交的重学草稿可继续，不会清除原完成状态。
- 每日新词目标调整为 30；所有到期复习继续保留。缺少已核对的语境来源或可用时间时显示缺口，不以复习、词形变化或展示词条凑数。
- 备份导入不再把同页重复保存通知误判成外部更新；其他页面的真实更新仍受一致性检查保护。
- 每日 AI 复盘与长期观察可以共同调整未开始课程的学习重点；保留已开始课程、原作、待订正与到期复习。本次未调用真实 AI 或语音服务验证评分效果。

升级后仍从正式目录双击“启动学习.cmd”。若后台仍是旧版，启动器会核对并更新服务；不要清空进度或重新配置密钥。原用户目录保持原位，开发测试数据不复制到正式目录。

## 现有材料与目标差距

本次正式构建保留 365 个日程条目与 1,842 份基础材料：

| 模块 | 基础材料数 | 统计边界 |
| --- | ---: | --- |
| 阅读 | 266 | 材料版本数，不能当作全部独立陌生文章 |
| 听力 | 283 | 原文与本地音频绑定；不全是真人、多口音材料 |
| 语法 | 201 | 练习材料数，不是 201 个互不重复的语法点 |
| 词汇 | 368 | 词组材料数，不是 8,000 词的完整语境课程 |
| 口语 | 145 | 训练任务数，不代表全部雅思口语能力已验证 |
| 写作 | 214 | 含基础与 Academic 任务；其中 Academic 任务 124 份 |
| 复盘 | 365 | 每日复盘条目 |

另有 688 份按条件加载的年度材料。上述数量保留既有内容，不等于从第 2 课开始每天 30 个新词的全年课程已完成。

真实浏览器的隔离旧档案例中，第 2 课仍为 3 组、19 个词项，按词形去重计 16 个初学词。这个结果明确表明：目标数字已调整，足量新素材尚未接通。第 2–11 课的 10 个关联单元、300 个静态候选词仍在待审包，没有在此版激活。

## 接下来的交付顺序

1. 接通第 2–11 课的 30 词关联内容：旧已学内容保留，新增内容按实际历史补入；语法、听读、说写围绕同一主题和词义展开。先让正常开始、保存和继续路径实际可用，再扩大课数。
2. 分批补全第 12–365 课。逐课核对词义、语法进阶、正文、音频、题目及旧词复现，区分普通学习与陌生测评。
3. 补齐语音的实际听感与使用条件检查、长期大量作品的保存恢复验证，以及真实 DeepSeek 个性化链路验收。
4. 用未见题和延迟复测检验听说读写进步；AI 估计、学习时长和材料数量不能证明或保证正式 IELTS 四项 7.0。
