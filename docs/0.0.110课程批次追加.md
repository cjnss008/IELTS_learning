# 后续课程按独立批次追加

0.0.110 是开发工具版本。家人正式版仍为 0.0.109，本版未新增页面可学课程，也未改动正式档案。

`tools/family-release-catalog.cjs` 从原始教学底稿和多个分别审核的课程包编译目录。每个包仍保留自己的 release、root review、unit、材料和音频绑定；总目录新增一批时，不用总目录的新哈希重写旧词组。目录明确为 `active:false`，不能把生成成功当作已在页面启用。

编译会重新读取并核验材料正文、题目、目标词原文坐标、词义、音标和音频；同一材料 ID、课程日或新增词头不得重复归属。传入上次目录后，旧批次必须逐项保持原值和原顺序，不能删去旧批次或改写旧底稿。检查失败时不改动调用方的数据。

本轮证据：正式 0.0.109 的七课、210 个目标词、70 份材料重新编译后，与现有 unit 及词汇来源绑定一致；两个合成测试批次追加后，原批次保持不变。另验证拒绝旧批次重排、删除、底稿变动、重复新词以及材料或音频变化。合成测试不构成真人学习或跨版本恢复完成的证据。

## 接续开发

1. 页面和后端按课程日选择对应批次；验证从旧词组草稿继续输入、录音、提交，以及新旧批次并存时的备份恢复。完成前不发布新的批次。
2. 统一旧任务与关联单元的词汇总量：当前每单元有 30 个目标词，但旧课仍有未学词，不能宣称每份档案的每日总量恰好 30。已保存旧题保留原始结果，新词和到期复习分别计量。
3. 优先编写第 11–20 课，并补全其余课程。每课检查 30 个新词在阅读、听力、语法与输出任务中的使用；词汇复习沿用实际表现与到期间隔，积压不能隐藏。
4. 对第 2–365 课和至少 8,000 核心词做逐项覆盖检查。每日 30 个不同新词共需要 10,920 个词头，需在核心词之外安排扩展词。第 365 课当前为年度复盘，尚需处理新词目标与年度复盘的结合，不能算作已完成全年每日 30 词。

2026-10-28 重新访问的参考页：[新东方 7600 词汇索引](https://ielts.koolearn.com/20140411/785955.html)、[IELTS Online Tests 语法目录](https://ieltsonlinetests.com/zh-hans/ielts-grammar/18880730.html)。它们用作覆盖核对线索；本工具不复制文章、释义或题目，也不将目录数量当作 Band 7.0 成绩证明。
