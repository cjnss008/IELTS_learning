实际接线：词汇App在已有reviewedRetention字段恢复前同步只读核验原codec及不可变legacy descriptor；没有字段时沿原初学，不建立空迁移结果。旧单页没有Bank时只走原v88校验，不支持未来release。原固定24词、48场景、144题、48h/7d窗口及原FSRS均保持。
