## 内容审核和原件

保留完整作者v1、官方原正文、选文、许可页面快照及每项编辑的UTF16坐标/哈希。BLS去掉没有随附表格的引导段；DNA显式改正一个印刷语法错误并删去容易误导的眼色简化示例。教学节选不会冒充完整官方页面字节。

工程复核另修复四份来源payload哈希采用不同JSON顺序的问题，并拒绝JavaScript负数slice坐标“碰巧匹配”的情况。题目、语法、单词及其原句包络均须是正文范围内的UTF16区间。独立原始红例及修复后绿例保留在签审包内；这属于AI内容/工程核验，不是教师或真实考生难度标定。
