# 原作答回显修复

“继续学习”曾在显示已提交答案之后，又建立一份空白练习。这会让已保存的选项、文字和录音引用从当前视图消失。修复后，重新进入时先恢复有内容的草稿，或回看已保存的原作答；重新练习通过“重新学”明确开始。

旧空白草稿和旧答案都保留。自动生成的空口语进度不算实际填写；已经录过的音频、待评记录、有输入的草稿与显式重学草稿继续保留原ID。模块内的“本模块已保存作答”可按材料找到旧答案和最近一次重学。

升级后关闭旧页面，再双击原“启动学习.cmd”，从“今日学习”进入模块即可。无需清空档案、重新配置AI/语音接口或重做原题。原材料版本、答案和评分不重写。

验证结论及其范围见[0.0.95验证记录](validation/v0.0.95.json)。新课程素材仍在另一个内容包制作，本修复不代表全部8000词及全年增强课程已验收。

词汇页面的“已保存词汇组”支持本课/前课筛选和完整展开，展示已存三次输入、三轮原答及跟读评分与原音引用。打开历史只读，不增加学习次数或重新计入掌握。三写三读的原音引用暂以保存信息展示，本次没有新增试听控件。

存在当前或其他页面的未交回忆稿时，历史提示记录仍保留，完成本次测验后再展开答案。没有未交稿时，即使当日预算已用完也可只读回看。缺少原版本或提交编号、原证据无法核验时显示待核对并保留记录，不猜造旧答案或用新题替代。
