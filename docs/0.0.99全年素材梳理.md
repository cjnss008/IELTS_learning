# 全年关联素材梳理：开发候选

此工具为课件制作提供可追溯线索，**不会改变用户的学习安排，也不是新课程发布**。它只读取经固定哈希核对的 0.0.98 公开课程、参考词库及年度材料；不读取用户配置、学习记录、媒体或凭据。请在可信、独占的开发快照上运行，避免其他进程同时替换目录。

在开发目录运行：

```powershell
node tools/build-annual-linked-supply.cjs --root .
```

默认只向标准输出打印统计。如果需要逐日候选，可显式添加 `--full`；报告会输出到标准输出，由开发者决定是否保存到独立的开发工作区。**不要将输出重定向到家人的用户数据目录或覆盖已有文件。**工具不接受输出文件路径，不自行创建报告文件。不同版本的公开课程需要先独立审核并更新固定输入合同；哈希或路径不匹配时退出。

当前结果使用原课表、已安排的公开材料及年度首次使用静态安排，只处理普通训练材料，排除关卡、保留卷与独立测评材料：

- 第 2–365 课共 364 天；第 1 课未参与本次梳理。第 365 课在原课表中有年度复盘条目；工具没有核验运行时先修或个人完成状态。
- 8,000 个参考词头中，3,755 个在当日安排的普通听读正文里有字面匹配。按“跨模块字面重合数、词频顺序”贪心选取且避免重复后，共 3,556 个不同候选；其中 35 天达到 30 个候选。这只是当前算法和素材快照的结果，并非最佳分配或可教学词数。
- 参考词表只有 8,000 个词头；如果第 2–365 课每天都要求 30 个彼此不同的新词，理论上至少还需要 2,920 个不同词头，实际仍须排除学习者已有的初学记录。到期复习不受这个数字截断。
- 各技能的字面重合不证明语义、词性、难度、语法目标或题目质量合适。正文可能已向用户曝光；候选不会被授予独立未见测评、掌握或考试分数信用。

每条候选包含材料 ID、版本、内容哈希、字段、原文哈希及 UTF-16 坐标。每项仍需核对具体语境中的词义与美式音频、材料许可与个人学习历史，再制作阅读、听力、语法、口语和写作，并经独立审核后才能考虑接入。第 2–11 课的隔离候选与此盘点相互独立，不代表已交付。

工程回归采用合成数据和公开课程副本；不等于真实浏览器、家人档案、真人音频或雅思考试验收。详细范围见 [0.0.99 验证记录](validation/v0.0.99.json)。
