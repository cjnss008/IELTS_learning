# 365天 Academic IELTS 四项7.0：现状、需求与推进计划

制定日期：2026-10-26。状态：已完成现状盘点和第一批兼容修复；下述课程重排尚未全部实现。本文是后续开发基线，不能作为学习效果已获验证的报告。

## 一、统一目标与不可变条件

面向成人近零基础、电脑本地学习、有麦克风的家庭用户，在365天的路径中，通过听、说、读、写综合训练，达到 Academic IELTS **每一项7.0**的能力目标。7.5可作为进阶训练余量，不替代四项分别验收。每天360分钟是学习、复习与休息共用的可用预算，不要求坐满，也不把计时或打卡当作掌握。

课程必须承担“目标是否得到充分训练”的责任：材料太少、反复做同题、没有自由表达、缺少真实听力或没有延迟检查，都属于产品缺口。不能把这些问题归因于学习者。与此同时，课程完成与能力达标必须分开记录；真实结果尚未通过测评时不能显示已达标。365天是规划目标，不是对未知个体考试成绩的无条件保证。

所有修改都保护既有题目和数据：已完成任务不追加必做量，不清零、不改分、不因升级重新变成未完成；已开始的草稿保留题目、选项、答案规则、顺序、录音和已投入时间。新增标准只约束新的学习任务。后续发现旧题有问题，应新建订正说明或替代题，并保留旧结果和更正来源。

## 三、需求整理与验收口径

1. **四项能力分别进步。** 页面应显示当前证据、目标差距和下一步任务。阅读高分不能抵消口语不足；读例文不能代替自由表达。
2. **先复习，再学习新内容。** 到期旧词、关键错误和语法知识优先；根据真实保持率、当前材料及剩余时间安排新量。取消每天机械22词与打开页面就生成词汇欠账。
3. **8000词融入课程。** 一个词在听读中理解，在词汇练习中回忆，在合适的口写任务中运用，后续换语境检验。复数/时态变化不重复凑词头，短语另计；义项和搭配另有覆盖记录。
4. **每日任务是完整学习单元。** 用户知道为什么学、用哪份材料、完成什么、接下来做什么。AI服务失败保留作答待重试，不判错也不判通过。
5. **六小时内动态安排。** 用同类真实完成耗时估算下一任务及休息；不够完成一份适当任务时结束或安排短复习，不强塞新课。未完成任务按依赖和优先级顺延，不无限累加成不可完成清单。
6. **难度来自内容和能力要求。** 同一题重复正确不代表进阶。新知识、迁移、速度、复杂度分别测量；升级不能只看课程编号、词数或当日耗时。
7. **既有素材优先。** 先给52篇、剑桥资料、现有课程标注能力点、难度、主题、出处、可用音频、答案和曝光，再选用。缺什么才找什么，不以新增文件数作为进展指标。
8. **题目与辅助要求。** 除词汇、语法外，提问用英文；练习允许跨模块划词与详细解释，独立测验禁止提示泄露。合成示范使用美式音色、区分人物并有合理停顿；真实多口音材料保留原音和来源。
9. **完整保留历史。** 新计划采用独立版本；已开始任务按原合同继续，新增内容进入后续任务。既有答题、原音、配置、错题与30天备份保留。

## 四、课程组织方法

### 1. 以能力阶段组织，而不是简单加题

下面是初始时间窗口，用来分配材料、预测进度，不是日历自动升级开关。已有真实入学测评可决定起点，各分项能力可以不同；阶段不通过时，安排同级新情境补强，同时更新预计完成日期，不修改历史完成状态。

| 计划窗口 | 主线 | 听读输入与口写交付 | 阶段检查 |
| --- | --- | --- | --- |
| 第1–28天 | 声音、拼读、基础句子与生活信息 | 短对话/分级短文；回答个人信息、简短问答、独立写正确句子 | 听辨与信息提取、句子理解、简短原音回答；不报IELTS分数 |
| 第29–84天 | 基础交际、时间/地点/经历、段落 | 多角色生活听力、短篇阅读；讲经历、描述比较、写连贯短段 | 换人物与情境仍能理解和表达；旧知识跨天回忆 |
| 第85–168天 | 独立语言使用、长句与段落逻辑 | 分级长文、较长对话/说明；复述、观点说明、段落论证 | 首次作答、改错后新题迁移，逐步增加限时要求 |
| 第169–252天 | Academic题型、论证与图表 | 适级学术材料、剑桥可用分科训练；Task 1/2、Part 1/2/3 | 任务覆盖、四维薄弱项、正常速度听读，逐渐完整限时 |
| 第253–330天 | 完整任务、弱项专项、词汇覆盖收口 | 独立听读整卷、两篇写作、完整原音口试；跨主题迁移 | 以不同未见材料核对7.0目标，留足订正和延迟复测时间 |
| 第331–365天 | 保持、复测、稳定表现 | 留存卷及未见主题；集中补短板，不靠最后一天突击新词 | 多次、跨日、无辅助的四项完整证据，给出已达标或具体缺口 |

课程按“有意义的输入、明确的语言学习、有意义的输出、熟悉内容的流利度训练”检查周内平衡，不能让背词挤掉听说读写。该组织原则参考Paul Nation的四条主线；比例是设计检查工具，不是每天必须四等分的计时任务。[研究原文](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/paul-nations-publications/publications/documents/2007-Four-strands.pdf)

### 2. 一个日常单元如何关联各模块

以“预约/改期”为例：先回忆到期的时间表达和旧词；听取一段预约对话并独立答题；阅读另一份通知，比较时间与原因；从两份材料中选取实际需要的新词、搭配与语法；完成词汇训练后，用不同信息进行预约口语，再写简短改期留言。随后用新场景检验，而不是背出示范原句。词汇条目保存材料ID、句子位置、义项和首次学习记录。

同日听与读可以围绕同一主题，但问题不能互相泄漏答案；阶段测验使用另外的未见主题和材料。基础期可以脚手架支持，后期逐步撤去提示、限制重听并增加自主组织。泛读泛听材料优先选择大部分内容已能理解的文本；生词密集材料单列为有支持的精学，不能把艰难逐词翻译当流利度训练。

每日界面以“到期复习→本单元材料与重点→听读理解→词句练习→口写运用→错题订正与复盘”呈现，并允许按真实薄弱项调整先后。原有已开始任务继续原流程，升级不让它们重新开做。

### 3. 8000词与间隔复习

**8000是年度去重覆盖目标，不是每天22词的硬指标。** 初步把完整首学覆盖窗口设在第330天前，为末期保留延迟检查；具体负荷必须经过材料覆盖和真实用时模拟再确定。如果已有词汇经诊断验证，单列为起点已知，不冒充本年新增。

选新词先看本单元真实听读材料和产出需要，再看频率、先修和全年缺口。没有上下文的候选不自动混入必做清单。词汇页同时显示“已接触、初学提交、未订正、延迟验证、需复习”，不得用其中一个数字代替全部掌握。

保留用户要求的初学三次输入、三次有效跟读及三轮测试，但纳入实际耗时核算；旧词复习按需要提取认义、拼写、听写、语境表达，不每次机械重做整套初学流程。词的主要义项、搭配和发音分别保留证据，不因一种题型正确就声称所有能力已会。

采用间隔提取练习，而不是照抄一条固定“艾宾浩斯日期表”。新卡用默认参数；真实回忆、提示使用、反应时间和错误记录用于调整下次复习。个人数据不足时不声称已拟合；足够数据后须用时间留出的预测检验再启用个人参数。研究支持间隔复习，但合适间隔还取决于保持时长，不能据此证明固定日程保证考试分数。[Cepeda等原始研究](https://pubmed.ncbi.nlm.nih.gov/19076480/)

先安排到期内容，但不允许复习无限占满所有技能练习。积压时降低新量、优先高风险知识、保留其余到期日期并显示预计延后；不能为了追8000进度隐藏未学、缩减复习证据或自动记完成。

### 4. 素材的具体角色

- **原52篇：** 按内容难度与词汇覆盖分配到适合阶段，可用于精读、语法析句、复述和流畅度训练，不当作52份万能零基础课。
- **现有原创和分级材料：** 负责前期桥梁、知识点练习和新情境迁移；逐份检查题干、唯一答案、音文一致、角色音色和实际难度。
- **剑桥4–15：** 按已核页码和适级程度安排分科训练；阅读、写作能用的先用，听力必须匹配真实音频。解析和同义资料放在首次独立答题后。
- **剑桥16–18：** 作为后期完整读写训练与校验来源，先核实可用分科页码、版本和曝光；不把教材浏览计作完成。
- **剑桥19及既有保留卷：** 优先留给末期未见检验。曾看过题目、答案、解析或对应同义资料的，不再标为未见。
- **GitHub资料：** 有明确许可的数据用于本地实现并保留署名；无明确转载权的教材提供出处和本地指页，不因公开仓库就新增整包复制。
- **补充来源：** 根据缺口选取British Council分级听读、语法与IELTS官方样题；先核实单篇可用性和难度。外链、试读或教材目录不自动成为已交付、已完成或已达标。

目前可用的补充入口包括[British Council分级语法](https://learnenglish.britishcouncil.org/free-resources/grammar)、[分级听力](https://learnenglish.britishcouncil.org/free-resources/listening)与[IELTS Academic官方样题](https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test)。真实音频来源不足是单列缺口，不用TTS伪装真题原音。

## 五、达标验证

官方听力与Academic阅读均40题，Band 7平均原始分参考约30题正确，门槛随试卷略有不同；内部8/10题短练不能照比例换Band。写作按任务回应/完成、连贯衔接、词汇、语法评价；口语按流利衔接、词汇、语法、发音评价。[IELTS官方评分说明](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)

产品内部拟采用最近一段时间内至少3次不同未见任务的跨日完整表现检查：四项均达到对应7.0标准才显示“内部目标证据达到”；一次高分、重复卷分数、AI给出没有依据的7分均不算。这个次数是项目验收规则，不是官方保证；正式考试成绩另列。若听读用尚未标定的原创卷，只报告正确数、覆盖与限制，不套官方分数换算。

写作和口语报告必须保留原稿/原音、评分依据、模型版本、各维度表现和分歧。双轮同模型只能检查一致性，不能消除共享偏差；有授权带分样例时进行盲评校准，不能靠统一加分解决偏低。口语缺少完整自由表达原音评阅能力时明确待验证；Ali跟读只能证明其覆盖范围内的发音表现。

阶段失败触发新情境补强和后续复测，不倒扣旧课程完成记录。进度预测持续报告“按当前真实保持率与可用时间，是否仍能在365天内完成覆盖和目标验证”，偏离时调整教学并明确差距，不偷偷降低标准。

## 六、按顺序实施的工作清单

| 顺序 | 交付物 | 完成标准 | 当前状态 |
| --- | --- | --- | --- |
| P0 | 现状、需求、目标和素材盘点 | 数量有实际索引依据，区分已交付/未激活/仅目录/缺音频 | 本文与只读审计已建立 |
| P1 | 历史保护与错误门槛修复 | 冻结课不扩充、旧完成不回退、新旧评分策略分离、草稿与媒体完整 | 第一批修复及专项回归通过；材料版本绑定仍待补 |
| P2 | 365天能力与素材矩阵 | 每阶段先修、能力点、首学/复习/迁移/测验明确；每项有真实可用材料引用 | 待实施，不直接把新素材塞进旧日期 |
| P3 | 8000词语境映射与容量模拟 | 词头→材料→义项→输出→复习可追溯；无上下文不凑数；真实预算下显示缺口 | 固定22已撤；完整双向映射与新容量模型待实施 |
| P4 | 统一每日任务与个性化 | 到期优先；任务适级；预估含休息；跨模块不重复计时；补强后用未见题验证 | 已有基础，需要按新矩阵整合 |
| P5 | 材料缺口和评分可靠性 | 优先补真正缺少的级别/题型/真实音频；记录授权、版本、校准与局限 | 已定位剑桥原音、完整自由口语及分级跨度缺口 |
| P6 | 隔离验证、真实服务与发布 | 数据兼容、课程依赖、音频、保存恢复、评分、预算、权限和主要页面逐项验收；更新README | 待后续阶段完成后执行；不混用家人正式数据测试 |

每一步先准备可核对的结果，再集成；失败就修复当前步骤，不靠生成更多材料跳过问题。未完成项保留明确状态，不能宣称全部课程已完成或教学效果已验证。授权范围内自主推进，不重复索要已给出的许可；遇工具明确拒绝的操作如实记录，不换通道绕过。

## 七、数据保护与发布约束

1. 原稿、录音与历史评阅采用只追加版本，配置和用户数据不写入课程源码或Git。
