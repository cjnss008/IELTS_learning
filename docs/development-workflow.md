# 单一正式目录开发

日常编辑和使用统一在 `\\mynas\family\IELTS_52篇学习包` 的 `main` 分支。原开发工作树仅保留历史与待整理候选，不继续修改、不作为启动入口，也不再安排 develop → main 的周期合并。

## 修改与验证

1. 在正式目录核对当前代码与 Git 差异，分小批次完成修改；不替换、清空或迁移真实用户文件夹。
2. 自动化测试使用临时目录与合成档案。需要浏览器或服务器测试时，使用一次性代码快照及独立数据目录，禁止测试读取真实配置、进度或录音。一次性验证快照不是另一维护分支。
3. 运行与修改相关的检查。课程或运行逻辑集成需完整回归、静态资源检查、明确参数的完整课程构建和内容审计；浏览器、真实接口、真人录音的验收范围分别记录。
4. 在 main 提交明确审核的文件。更新 VERSION、CHANGELOG 和必要验证记录；README 只描述功能与产品特性。
5. 每十个小版本同步 GitHub，或按用户明确的提前同步指令执行。不强推、不重写历史。

## 家人继续学习

家人保存当前草稿后，重新双击正式目录的“启动学习.cmd”，由启动器核对并更新本机旧服务，再刷新学习页面。NAS 的代码更新不会直接替换其他电脑内存里的旧服务。

不清除浏览器数据、不删除用户文件夹、不重新建立学习档案。已保存配置、原答案、草稿、学习次数和录音保持原位。

## 历史开发工具

tools/start-development.cjs 保留旧独立目录的隔离保护，不在正式目录强行启用它。旧开发目录、未提交素材和临时验证输出未经整理不得整包复制到正式版。正式更新仅接入已审核的代码与课程材料。
