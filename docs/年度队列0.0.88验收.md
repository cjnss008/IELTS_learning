# 年度队列0.0.88验收

## 0.0.88 开发版：档案缓存与下一份任务的完整核验

档案从实际存储读回时仍做完整格式、内容与归属校验；同一份已验证且不可变的原稿可复用解析结果，减少连续刷新时重复处理。未验证数组、同ID同版本但内容不同的记录，以及恢复／切换后的数据继续全量核验。没有新增持久化缓存键，也不改写原始答案、历史评价或材料合同。

年度追加任务开始前、等待接口后和创建草稿前重新检查当前原稿、待评状态、到期复习与包含休息的总预算。修复屏幕旧提交结果覆盖最新评价，以及已完成本课后因两种摘要混用而一直等待的问题；提交最后一项、查看历史作品后均可从当前任务衔接。自动读回通过真实Records入口完成，无需手工重新载入档案。

同一份追加练习的跨页启动保护保持到草稿写入用户文件夹。中断后只有当前来源完整、无原稿、无草稿且没有活跃启动时才释放未保存的安排；已保存、待评、旧版材料及缺少可靠活性证据的历史启动均保留。恢复检查先读一次688份队列快照，再核对候选，不逐条重复解析整份档案。返回缓存页面时建立新控制器，已存输入与历史保持。

本版采用37项必要组件、41项实际文件绑定，最大44项；新增缓存组件须按精确路径和页面执行顺序校验。正式组合重建继续保留GSA公开80份与688份全年普通材料。完整默认回归2324项：**2322通过、0失败、2项可选或环境条件测试跳过**；静态检查27页、745处引用、122个脚本通过。组合构建1828份材料、365课表和原80份公开安排保持；688份原年度正文逐字节相同，实际隔离本机HTTP逐份核验并检查10个实际脚本/数据文件。另有40项root组合回归和9项独立合成路径检查，均通过。

家人稳定版仍为0.0.81，本版只在develop提交。真实浏览器访问仍被工具保存权限／管理策略拒绝；合成DOM、实际本机HTTP和自动回归不替代这一验收。当前修复不证明长期学习成效，更多新词语境、保持复习和真人材料仍分批开发，未把候选数量算成已经教会。



材料数量不作为能力证明；本版没有扩大课程材料总量。用户原稿、旧材料合同和实际媒体未读取或改写。

后续单独工作包括：8000目标的语义与词族质量、已审词48小时／7天保持训练接入、现代真人材料的适级排课，以及大量已完成年度任务的性能画像。候选内容复核不等于已教会或已入课。
