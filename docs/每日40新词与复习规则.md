# 每日40个新词与全部到期复习

这是后续课程的实施规则，词汇参考表、已安排内容、实际完成和延迟回忆分别统计。家人已交的答案、录音、成绩、草稿和已完成课次保持原样。

## 每日顺序

1. 继续未提交的复习原稿，完成所有已到期回忆和错词订正。到期队列不按条数截断，也不因词汇参考分钟用完而消失。页面一次处理一道题，分批呈现不减少必做量。
2. 通过后，再安排当天40个真正的新词。只接受与适级听读材料有明确关联的词，已学词、词形变体和再次出现的词不重复算新词。来源不足必须补教材，不能从词典随机凑满。
3. 每个新词沿用三遍正确输入、三次独立跟读评测，再做补全、中文写英文、听写三轮。只有实际完成的记录计入初学量。
4. 复习答错要保留原答案和错因，先订正，再按间隔重新检索。同日提示后的答对不冒充跨天独立记忆证据。等待短间隔时可以转去听读或休息，不显示全部掌握。
5. 到期复习没有每日条数上限。六小时仍是学习和番茄休息共用的可用时间；预计放不下或主动结束时，余下任务保持待完成并顺延，不标成完成，不删除最早任务。

40是新词教学目标，不能因为材料缺口或旧数据只有少量词，就把页面数字改成40。当前8000核心词范围按约200个实际初学日安排，随后继续延迟复习、搭配、义项和听说读写运用。是否扩展为全年持续40个新词、约1.46万词，需另有足够新材料和完整安排。

## 怎样判断“记住”

当场答对仅表示本次完成。软件记录闭卷拼写、听音识词、语义辨认及语境表达的实际结果，结合后续间隔检索安排复习。提示、看过答案、重学和真实无辅助回忆分别记录；新错误会撤回相应的掌握状态。已经完成的原题不重新改分。

间隔由真实表现调度，保留1天、数天及较长间隔的回忆机会。不能把固定复习表或某一天全对当作永久不会遗忘的保证。每日必须完成的是所有当前到期及未解决的错题，未来尚未到期的正常复习继续按原计划出现。

## 365天制作目标与验收口径

以下是待逐批补齐的制作目标，不能当作当前已交付总量，也不能单靠数量证明考试分数。

| 项目 | 最终制作目标 | 计数方式 |
| --- | ---: | --- |
| 课程 | 365天 | 364个教学日及第365天年度复盘 |
| 核心词头 | 8000 | 每个真正新词头只计一次；复习、变形、搭配另记 |
| 阅读 | 728篇 | 不同正文；重读、慢速版和题目变体不增加篇数 |
| 语法 | 260个知识点、至少5200题 | 以可单独解释和检验的概念去重；标题和材料ID不等于知识点 |
| 听力 | 780份 | 不同脚本和对应完整录音；单词音频及同稿慢速版不重复计数 |
| 写作 | 520个独立题干、728次任务 | 520次初稿和208次实质修改；含240基础/段落、140 Academic Task1、140 Task2题干 |
| 口语 | 728次 | 364次示范/发音训练、364次自主表达；逐词跟读不额外计为完整口语任务 |
| 完整Academic模拟测评 | 40套 | 听力160部分、阅读120篇、写作80题及完整口语均包含在上列总量内 |

模拟测评保留独立来源、未见性和无辅助条件，不能以已经练过的同题成绩代替。训练密度随实际能力上调，完成数量、AI估计、发音百分制和正式Band分别记录。

正式Academic结构为听力四部分、阅读三部分、写作两任务、口语三部分。上述制作数量是本项目设计，不是官方规定：[IELTS Academic官方考试结构](https://ielts.org/organisations/ielts-for-organisations/test-types/ielts-academic-test)。
