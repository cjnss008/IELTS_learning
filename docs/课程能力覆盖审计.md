# 课程能力覆盖审计

审计日期：2026-10-26。本文审查公开课程、排课和来源，不读取个人学习档案、麦克风、密钥或正式服务配置。内部训练目标是听说读写各7.0；现有证据不能保证零基础学习者完成课程后必然达到该成绩。

## 官方目标与需要的证据

Band 7要求能较好处理复杂语言与详细推理，同时仍可能出现偶发错误。听力与Academic阅读各40题，官方Band 7平均参考约为30题正确，实际原始分门槛随试卷变化；这不能用于给本项目的8题或10题短练换算Band。写作按任务完成／回应、衔接、词汇、语法评价；口语按流利衔接、词汇、语法、发音评价。写作Task 2权重大于Task 1。见[IELTS官方评分说明](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)。

听读需要未见的完整材料、真实首次答案与播放条件；写作需要自己的完整原稿；口语需要未套用例文的自由表达原音和覆盖完整任务的听音评阅。题型和完整任务参照[IELTS Academic官方四项样题](https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test)。官方样题或解析被看过后，不再称为未见证据。外链访问、学习时长、8000词目标和Ali朗读0–100分均不代替这些证据。

## 本轮具体改动与尚未完成的范围

第一课原排课保持不变。第二课保留全部旧材料，追加10道新语法题、124词阅读与8题、115词三角色听力与8题、57词干净口语示范、至少40词的6—8句写作任务，并从新增源原句派生7词词组。新增问句、not否定、we/they与规则复数；旧I am/you are明确作为巩固。已开始与已完成课程保持原快照；新增ID只进入后续未开始安排，不改写旧原稿、成绩或完成要求。

全期扩展计划按52周各新增2份阅读和2份听力，另为21—52周每周新增Task 1/Task 2；同一周材料会有明确首学与巩固轮换，不声称每天都有独立新篇。待编写、未审核、缺音频或未通过哈希核对的任务不计作已交付；正式课程完整性仍以正式构建与相应审计为准。关卡和末期保留卷不改，不把扩展练习混进保留测验。该计划不能称为“365天全部独立材料已重写”。

第3课起语法排课减少无标记的每日2/3复用，保留本日首次安排包与明确复习包；这改变已有材料的安排，不自动证明新知识充分或长期迁移成立。未来还需逐题核对语境、唯一答案、原文依据、难度跨度与后续未见表现。

## 官方分级补充与练法

零基础先完成本地桥梁，再试[A1新同学会面](https://learnenglish.britishcouncil.org/free-resources/listening/a1/meeting-other-students)；先不看稿听取人物和信息，再核对、重听漏段，并用新信息独立复述。另有[A1听力目录](https://learnenglish.britishcouncil.org/free-resources/listening/a1)、[A1阅读](https://learnenglish.britishcouncil.org/free-resources/reading/a1)、[A1口语](https://learnenglish.britishcouncil.org/free-resources/speaking/a1)、[A1写作](https://learnenglish.britishcouncil.org/free-resources/writing/a1)。

后续按实际程度选择[A2](https://learnenglish.britishcouncil.org/free-resources/listening/a2)、[B1](https://learnenglish.britishcouncil.org/free-resources/listening/b1)、[B2](https://learnenglish.britishcouncil.org/free-resources/listening/b2)、[C1](https://learnenglish.britishcouncil.org/free-resources/listening/c1)官方听力分类。只核验分级主页的条目不伪称逐篇已审；CEFR页面标签不直接换成IELTS成绩。本地仅链接原站，不打包受版权原文、音频和试题；外链使用不自动写入完成、掌握或Band记录。
