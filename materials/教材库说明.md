# 本地教材库

打开项目根目录的 `本地教材.html`，可以离线筛选与打开教材。全部跳转页码都是 PDF 阅读器从 1 开始的物理页码，不是书上印刷页码。浏览器未执行 `#page=N` 时，在 PDF 阅读器手动输入该页码。

本次来源为用户指定的本机教材目录，用户已明确授权教材原件随本项目代码上传 GitHub。导入不改动源文件；只用本机 SHA-256、pypdf 和本地渲染核实，未把整本 PDF 发给外部 AI。`textbook-catalog.json` 与 `../assets/textbook-catalog.js` 是同一索引的 JSON 与直接离线加载版本。

## 本批资料

- 42 个来源文件，按 SHA-256 合并为 41 个唯一 PDF；剑11真题和剑11真题(1)完全相同。
- 16 册主卷覆盖剑4–19，64 个主卷试卷起始物理页与各册听读答案区起始已核实。剑12这份原书编号是 Test 5–8。
- 剑4–10含 Academic 主卷和另外的 General Training 内容；只索引 Academic 主卷。剑11–19已从封面或标题页核实 Academic。未确认类别的解析/同义资料保持“类别未确认”。
- 剑16–19额外核实各套阅读与写作起始页，便于后期读写限时训练；其他主卷没有核实的分科页码不会凭固定偏移生成。
- 本批没有任何配套听力音频。封面的 With Audio、二维码和听力原文不等于本地已有音频。未补齐并核实原版对应录音前，不能把这些卷算作四科完整模考。
- 核实范围只包括封面/首页、所列目录与章节起始/答案页；未逐页校勘全部正文、扫描质量或答案。

## 周次与保留

`textbook-training-map.json` 提供第21–52周的建议，按实际掌握情况由课程安排使用：第21–36周可拆分剑4–7；第37–48周用剑16–18的12套读写限时任务；剑19四套留给第49–52周。剑8–15其余卷可用于补强。全部建议明确缺听力音频，不自动作为完整测评完成证据。

末期保留也包括剑19解析及覆盖剑19的跨卷同义合集；页面默认折叠其 PDF 入口。展开说明不计已见，打开 PDF 才登记。PDF 阅读器允许跳往其他页，若看到其他试卷请手动补记。已有已见记录时，应另选未见材料，不以更改标签恢复陌生性。

## 新增文件后扫描

需要 Node.js 与本地 Python 的 `pypdf`。项目的本机运行环境会被自动尝试；也可显式指定 Python。没有解析器时可先导入原件，但页数保持未核实；安装后再扫描补齐。

```powershell
python -m pip install pypdf
node tools/import-textbooks.cjs --source "\\mynas\family\教材"
node tools/import-textbooks.cjs --source "D:\我的新教材" --python "C:\Python\python.exe"
```

将新增 PDF/音频放进指定来源目录后运行。脚本跳过隐藏目录、NAS `@eaDir` 与符号链接；按文件指纹去重，复制原件到 `textbooks/`，音频到 `textbook-audio/`。已导入原件继续保留，不因这次来源只包含新文件而删除旧材料。无参数时只重新扫描已导入 PDF。源文件与学习记录不被修改。

新文件的类别、章节页码和音频对应关系一律先显示“未核实”。添加经过本地检查的章节时，在 `textbook-verification.json` 的 `documents` 下以完整 SHA-256 为键登记：

```json
{
  "academicStatus": "academic",
  "academicEvidence": "PDF第2页标题页明确Academic。",
  "method": "local-render-visual-review-and-local-text",
  "reviewedAt": "2026-10-24",
  "pagesReviewed": [2, 10],
  "anchors": [{"kind":"test","page":10,"label":"Test 1 起始","evidence":"本地核对试卷标题和Part 1。"}]
}
```

只登记实际看过的 PDF 物理页，然后重扫。文件内容改动导致 SHA-256 改变时，不沿用旧文件的人工页码。

音频会列入 `textbook-catalog.json` 的 `audioFiles`，但不会按文件名自动匹配试卷。需逐一核实版本、Test、分节与录音完整性后，才能安排对应听力任务；现阶段音频列表仅提供下载与核对来源，尚未把新增音频自动变成课程播放器任务。

## 记录与备份

教材曝光使用 `IELTSProfiles.storage()`，键为 `ielts52-textbook-exposure-v1`，独立于每个学习档案。`preview=1` 使用会话存储。打开单套试卷/已核实分科页记录该套已见；打开整本、目录、答案区则按保守规则记录整册已见；解析与同义资料会记录其相关主卷已见。

初始未登记不等于已经核实“从未见过”。自报未见可登记或更正，但保留首次已见历史；不会据此产生 Band、掌握或考试达标结论。页面可以单独导出/合并本档案教材记录，不含正文或密钥。学习记录不要放进 Git。

## Git LFS

所有 `*.pdf` 和未来导入的 `materials/textbook-audio/**` 已配置 LFS。首次获取完整副本需安装 Git LFS 后执行 `git lfs pull`。只拿到约百字节的 `version https://git-lfs...` 指针时不能阅读教材。
