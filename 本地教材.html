    新增教材或音频后重新扫描

    把新增 PDF 或音频放进原教材目录，在本学习包目录运行下面命令。扫描只在本机进行：按 SHA-256 去重、复制新原件、读取页数并重建离线索引；已核实页码按文件指纹保留。

    node tools/import-textbooks.cjs --source "\\mynas\family\教材"

    也可替换为其他本机目录；用 --python "Python完整路径" 指定已安装 pypdf 的 Python。仅重扫已导入教材可运行 node tools/import-textbooks.cjs。完成后刷新本页。

    新文件的考试类别、试卷页码和音频对应关系默认“未核实”，不会按文件名猜成可用完整卷。核实步骤与音频补齐说明见 教材库说明。

    备份本档案的已见 / 未见记录

    记录只属于当前学习档案和浏览器。下载备份后可在同一档案导入；导入合并记录，保留首次已见历史，不包含密钥或教材正文。

    “标为未见”是个人更正，不会清除已记录的曝光历史；末期测评前仍需检查自己是否看过题目、答案或相关资料。

    来源与核实范围

    全部 PDF 原件以 Git LFS 保存。若打开后只有几行 version / oid / size 文字，请先在有 Git LFS 的完整副本运行 git lfs pull。跳页取决于浏览器的 PDF 阅读器；不能跳页时在阅读器输入所列物理页码。

    扫描件的印刷页码和 PDF 页码常常不同。本索引只把已实际核实的物理页做成章节链接；未逐页校勘教材正文或答案。
